### 3.1 标定真实表面，而不是按 link 名字或视觉猜法向

在实际被选中的 L20 左手 USD/碰撞资产上标注拇指末端**掌侧指腹工作面**。这是一项机器人表面语义标定，不预设模型具有真实软组织、柔性材料或触觉垫。先确认该表面属于哪个刚体/哪个mesh；不能把 `thumb_link4` 整体、link原点、整个末端球壳或“离果实最近的点”当成指肚。

产出一个带版本/哈希的 `thumb_pad_region`：刚体/mesh路径、局部坐标系、区域三角面或明确边界、各位置外法向、容差、可视标记图，以及渲染mesh与实际 cooked collision 表面的对应误差。指肚区域只作语义标记，不增加碰撞盒、代理掌托或隐藏支撑；拇指侧面碰撞保留，不能用关闭侧面碰撞来迫使通过。

未知的局部轴、指肚边界和接触法向符号，在完成标定前一律写 `UNSET/UNKNOWN`。不根据文件名或左右手镜像经验直接选 +X/+Y/+Z。应有正视、侧视和局部坐标示意，区分指肚、侧面、背面、指尖端与近端。

若 cooked hull 显著填平/移位真实指肚，单独记录碰撞近似缺陷；先修复相应碰撞近似并生成新资产版本，再重做基线。不得随意缩放拇指、加摩擦、减重、放宽驱动力或穿透阈值来制造可达。

### 3.2 逐接触点、逐物理子步采集

优先复用现有 `physical_contacts.py` 已调用的 PhysX packed `get_contact_data(1/120)`。现代码只消费其中 separation；未来还需读取 normal force/impulse、point、normal、counts/starts，以及具名body↔fruit过滤对应关系。不得把 `contact_pos_w` 的平均接触点作为唯一证据：多个侧面点的平均位置可能落到指肚区域。

每个真正的120 Hz子步至少记录：env/episode/物理计数与dt、sensor/filter/body/shape可用身份、counts/starts及缓冲状态、接触点和法向、力/冲量单位与dt、拇指刚体world pose、局部接触坐标、pad/side/back标签、分类置信/缺失原因、支撑F/T、原七类硬故障。把点转换至已标定的刚体局部坐标；接触点若由SDK定义为对侧或中点，必须先完成对应表面投影/符号标定，不得直接假定在手表面。

保留 `NO_CONTACT`、`PAD`、`NON_PAD`、`UNKNOWN` 四种状态。无接触不等于数据缺失；缓冲溢出、错env/body映射、法向/姿态非有限、缺帧或不明确表面归属不能默认为PAD。沿用连续计数、dt=0不计、缺物理步中断、逐env reset隔离和硬故障粘滞规则。新提取器每子步读取一次，避免为点位/穿透/力反复同步读取同一接触缓冲。

本轮发现本机ContactSensor调用点与测试mock的tuple含义不一致：实际调用点按第二项取points，mock却按第二项定义normals、末项定义patch IDs。mock不能作为GPU返回布局依据。P1/P2必须核实实际加载版本、数组shape/单位、counts/starts、sensor/filter身份、一个已知正面与一个侧面接触的数值几何；不需要扩成SDK资格项目，但未绑定字段前不能训PAD奖励。本机今天静态包元数据为isaaclab6.1.14/isaaclab_physx1.1.3，不能靠环境目录名猜版本，也不能回填旧运行环境版本。

### 3.3 新的硬成功规则

沿用旧规则中撤支撑、至少两指、1秒/120真实子步、速度≤0.05m/s、漂移≤10mm、无原硬故障的条件；新增：**每个计入持握窗的子步都必须有已验证指肚的真实受力接触，并有至少一根非拇指手指真实接触。**

拇指侧面/背面等非指肚的承载接触不能计入合格抓握。允许的仅是经无接触/边界标定确定的数值噪声底，不能用随意的10%侧面载荷占比豁免。`F_pad_min`、`F_nonpad_noise_max`、位置/法向容差须在预检查后冻结；0.08 N只可作为继承的参考起点，不能把旧聚合范数阈值直接当逐点标量力阈值。若噪声容差需要大到包住侧面，应修正数据或几何而不是扩大PAD区域。

任一子步发生有效的非指肚承载、指肚失去接触或UNKNOWN，即清零新指肚持握streak；普通接触调整可以继续探索，原过载等硬故障仍终止。不允许先指肚触一下，再靠侧面/掌托完成剩余时间。side-only、拇指完全悬空但另两指接触、接触点均值落入PAD但实际点均在侧面，均必须失败。

位置边界加正确表面法向用于识别指肚；额外的几何对向分数可作奖励，但不宣称数学上的完整六维力闭合。真实抗重力持握仍由动力学与无支撑条件验证。

## 4. 第二优先：可达性、动作与温和接触

在任何PPO之前，针对固定果实位置做一次有限的无碰撞起始姿态/受限关节扫描，验证指肚中心与法向确实能到达可用接触区域。记录各拇指轴的小幅动作前后，实际关节响应、pad中心/法向变化、限位/裁剪/滤波作用。只在reset设置初态，回合中不得写果实状态。

对当前14D映射做受限有限差分：检查拇指间隙、pad法向两分量等任务方向是否有独立控制作用，尤其是clip和 `max(global_flexion,0.92*opposition)` 饱和区域。先判断“姿态/动作表达不足”还是“策略没学到”，不要求先得到完整成功教师。

优先保留14D和现有安全边界：能在现有映射下到达正确指肚姿态，则只改参考姿态、观测和奖励。若确实欠驱动/强耦合导致不能同时调整对掌朝向与闭合，再为新任务重参数化拇指对掌/弯曲残差，必要时增加最少的独立拇指维度。新映射必须另存版本，不能沿用旧actor解释新动作。禁止改旧vendor文件的全局语义影响其他任务。

闭合采用有界、平滑的真实关节目标；新增动作→目标→过滤后目标→实测关节→接触力的时程记录。软接触阶段让靠近速度逐渐降低，对闭合过冲和力增长率加代价；不能用瞬移、teleport、改果实速度、忽略碰撞或直接强制joint state获取接触。闭合预程序若使用，必须作为单独对照，证明PPO相对同程序零策略有额外作用。

受力改进分两步：先降低撤支撑前的碰撞尖峰，再改善持握稳态载荷。每指保留旧hard指标用于连续性比较，同时新增逐点正法向标量和、冲量、受力部位及分位数。新总载荷指标与旧max-body-vector-norm不是同一个量，不可复用同名15 N阈值；新约束需经真实可行性预检查冻结，旧硬限制不得静默放松。软范围先作偏好/奖励，不能在没有材料/损伤校准的情况下称“无损抓取”。

力质量指标直接从真实物理子步提取，不用episode采样峰值替代。本次40个回合的原始峰值均有至少一指比摘要采样高0.1 N以上；失败中的最大拇指峰23.1867 N，原硬门已判为过载。降低冲击的目标是减少这样的物理尖峰，而不是把它从低频摘要中隐藏。

## 5. 第三优先：观测、奖励和 PPO 学习

### 5.1 可观测的新任务

新actor可增加少量与任务直接相关的特征：果心在pad局部坐标中的位置/距离、pad外法向相对果心方向、实际pad与non-pad受力/接触标记、对指接触方向、相对线/角速度、支撑阶段、过去执行动作。接触点只在接触后出现；无接触时提供可几何计算的距离/朝向和有效性mask，不把NaN补成“好接触”。部位真值需要在actor、critic、奖励和最终审查中使用同一版本定义。

先用上述小型前馈特征，不默认上RNN/大网络。若掉落诊断证明单帧不能区分滑移趋势，再比较3–4个策略步的短历史或小型循环模块，作为独立消融，不一次合并所有改动。

现有动作滤波器含速度/加速度等内部状态，actor只看到部分执行历史；这是否造成关键部分可观测问题尚未证实。可先测相同可见状态在不同滤波历史下的后续响应，若差异确实影响接触，再增加最少的滤波状态/短历史，不默认把RNN作为修复。

主线默认新建actor、critic、optimizer和归一化，独立训练新任务；不强迫延续已学侧面夹持的模式。旧v6只作只读对照。可选热启动属于额外实验：只能读取原权重副本，显式说明拷贝哪些均值层、哪些新输入列初始化为零、哪些归一化状态重新估计；动作/观测语义不同的层不得直接继承。旧normalizer不能因维数相同而盲用，critic/optimizer必须重建。该迁移不算PPO学习，也不修改原文件。

### 5.2 奖励结构（先冻结量纲，再调权重）

| 项目 | 建议机制 | 防作弊约束 |
|---|---|---|
| 接近与指肚朝向 | 可达pad表面距离/法向误差的势差shaping | AABB/距离只作引导，不作接触真值；reset首步无奖励跳变 |
| 正确接触建立 | 真PAD受力接触及至少一根对指接触 | 不能只数手指或只看link原点；真正逐点验证 |
| 侧面/背面承载 | 连续non-pad载荷代价，且不累计指肚streak | 不把侧面同时计入接触奖励；不因总回报高选错部位策略 |
| 对掌与载荷平衡 | 基于真实接触点/法向的对向代理分数 | 代理分数不标为完整force closure；仍需真实动力学持握 |
| 低冲击、适度用力 | 接触建立速度、力增长/冲量、软范围超出与不必要用力代价 | 不仅在超过15 N后才惩罚；软目标先验证可行，不能奖励不碰物体 |
| 抗滑与稳定 | 真PAD合格后才给撤支撑持握进度、漂移/滑移稳定奖励 | 奖励进度与硬成功streak使用同一120 Hz定义；错误接触不获持握奖励 |
| 成功/失败与动作平滑 | 真成功bonus、drop/hard-fault代价、适度动作变化代价 | 保留硬失败和完整分母；平滑奖励不能压倒接触纠偏 |

先记录逐回合、逐更新各项奖励贡献与终止原因分布，再少量调权；现有末策略步4-env快照不是整回合奖励分解。不要通过给指肚一项巨大bonus掩盖掉落/过载，也不要一次改奖励、摩擦、质量、动作维度和PPO参数。

### 5.3 训练起点与样本使用

初始保持v6已稳定运行的 `4 env / 64 steps / LR=1e-4 / std=0.08 / entropy=0.003 / 4 epochs / 8 minibatches` 作为对照超参起点，不把它称作新任务最优值。新actor的探索范围可在小预检查中按实际关节/动作裁剪分布验证，若0.08不足覆盖指肚可达区域，再单独比较探索方案，不回到已证不稳定的大并行/高噪声设置。

每10轮算法update保存一个新检查点并作小批独立评估，记录实际环境交互transition和minibatch优化步，区分两者。网络大小先保持；先增加有效且正确标注的交互样本，不能把epoch重放当成新增物理经验。记录实际KL、clip fraction、entropy/std、value explained variance、梯度范数/有限性、动作裁剪率和每项奖励规模；当前配置的 `desired_kl` 在fixed schedule下不自动等于KL止损已启用，若新增KL提前停止需明确实现和验证。

出现连续两次独立检查的指肚成功率或主要失败指标退化，即停止沿该支线继续堆更新，保留最佳/最后/失败记录，只针对已识别的一项原因调整。不要再次把“训练成功回合变多”直接作为真实进步。

## 6. 分阶段执行与停止门槛

| 阶段 | 最小工作与产物 | 必须满足的门槛/停止条件 |

| P0：表面与坐标标定 | 新分支；pad区域配置/哈希；左右/侧/局部图；USD→碰撞表面对应；动作轴与pad位姿小幅响应 | 指肚区域和坐标约定明确；不能只拿link名称。若可达性/碰撞近似未解决，停止训练准备，交付明确问题 |
| P1：接触观测与判据 | 复用packed接触；标定力/冲量dt、normal符号、body/env和surface对应；新120Hz pad streak与少量针对性CPU测试 | side-only、背面、无拇指、均值点误判、短触后侧面、0-dt/缺步/溢出/NaN等负例必须拒绝；有效pad正例可通过。CPU合成例不算物理成功 |
| P2：有限物理验证与新基线 | 1–4env，少量已知pad/side/无接触情形；旧冻结策略只读重评、初始策略、开掌在新判据下各20次 | 不改旧权重。旧观测须用显式评估适配器保持原114D语义，新增observer独立打新标签；不能放宽常规checkpoint兼容检查。若旧终止会截断新评估，则用新只读评估器统一终止时序，不能沿用旧早停方式比较。未校准/UNKNOWN不能从分母删去 |
| P3：指肚抓握学习 | 新actor主线，先固定67mm/位置；小段PPO；记录pad/side时长、过载时刻、滑移、力量与奖励分解 | 首个里程碑：同一新权重两组独立20 reset各≥10新PAD成功；初始/开掌新PAD成功应为0。每个被判成功的窗必须100%满足新部位条件，无UNKNOWN/非pad承载。未达到则报告真实结果，不改门槛 |
| P4：低冲击和稳定性 | 在正确指肚接触基础上分别优化闭合阶段与持握阶段；小范围物体初态/接触扰动 | 和同语义新基线比较：过载率、力峰值P95、掉落率下降且PAD成功不退步。软力/峰值改善目标在P2力可行性检查后冻结，不预先保证数值 |

## 7. 最小实验矩阵与资源安排

采用顺序实验，每一列只有清楚的差别；后续全部使用**同一个新硬成功规则**，不能通过不同判据比较奖励方案。

1. B0：旧v6冻结策略只读 + 新独立接触observer；fresh与open对照。
2. E1：新PAD成功/观测 + 现有可用14D动作，最小奖励修正，固定原物理。
3. E2：E1 + 正确接触位姿/低冲击用力奖励，仍保持同超参；定位是否降低12次撤支撑前过载这一主因。
4. E3：仅在P0证明动作表达不足时，比较E2 + 最小拇指动作重参数化；若P0已证14D足够，就不做该扩维实验。
5. E4：对已通过PAD的较优方案逐项加入短历史或有限扰动；不同时改两项。最终较优方案补另外2个训练seed，而不是用一个seed挑幸运模型。

控制奖励/观测不同的实验时，其余PPO超参、物体、驱动和训练交互预算相同；改变动作/观测语义的分支从相同的新初始化规则开始。热启动如果另测，必须另列其源策略、迁移层和状态重置，不与fresh样本效率混为一谈。所有失败/未完成/UNKNOWN都保留。

比较E1/E2时，新PAD硬判据与新观测是共享任务基线；两者之间只增加用力/冲击优化这一组变化，不能把同时改变多项后的提升都归因于某一奖励。需要比较“增加PAD观测是否有效”时，另设移除这些新特征的消融，但使用同一硬判据。

分开训练集、用于每10-update筛选的开发评估集、以及最后一次才解封的最终测试集。不能用反复查看同一20-reset测试集挑最佳后，再把它当独立泛化证据。只改变随机种子、却完全不改变固定物理初态/参数，不等于引入实际场景多样性；P5须显式列出有界位姿/动力学扰动和各自范围。范围在P2可行性检查后冻结，超范围不作泛化声明。

建议未来首轮执行包先限于 **P0–P3的前2小时受监控仿真**，P0/P1代码时间另记；在明确出现PAD接触学习后再使用更多预算。参考拆分：接触验证/基线最多30分钟、两条短训与中间评估最多60分钟、最终完整评估/录像预留30分钟。模型与几何未通过前不跑主训。当前旧总账已用10579.871489秒/43200秒，余额32620.128511秒仅是历史预算状态，本计划不自动授权花掉余额或重置12小时总账。

同GPU仅一个PhysX进程；继续外置盘输出/cache/视频和磁盘保护。4env可先保持，不重复已失败的32env。总账必须覆盖失败、中断与重试。两小时不足三seed验证时如实标为候选，不压缩分母或省掉对照来声称可靠性完成。
