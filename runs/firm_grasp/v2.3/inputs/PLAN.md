# F3/F4接续计划：先稳定建抓，再增强抗扰与学习收益

日期：2026-10-19。供一个外部目标模式对话执行；本地没有因此恢复训练。用户要求的同模型/同思考强度、最多2个并存叶子子Agent优先于旧economy技能的异构角色建议。

## 1. 继承现状

F2已接收，可作为继承来源；不退回旧的“F2无G1”历史结论。当前最合适的F3源码是v2.2，已存在真实PPO更新、正确指肚三指保持3秒以及开发抗扰成功。当前学习效果尚未达到预期：

|同一新条件下的actor|quiet|force|torque|总计|
|---|---:|---:|---:|---:|
|旧v1.6经显式动作适配|0/8|0/6|0/6|0/20|
|v2.2未更新常量先验|2/8|1/6|0/6|3/20|
|v2.2 PPO update1|1/8|2/6|0/6|3/20|

开掌0/4。开发三模式各1/4；独立力矩重载1/4。不能合并这些不同分母，也不能把旧actor在新条件的0/20说成旧版原条件表现。

关键诊断：10个更新actor的扰动失败都在脉冲前中断合格窗；重复reset的case2成功、case6失败，首记录下发动作相同但初态有小差异。只说明建抓/重置动力学敏感，不证明reset代码错误。部分失败还有较晚的长时间G1接触，但不满足严格早期G2，不能重新命名为通过。

v2.2初始化是新随机编码器加常量输出先验，**不是完整F2 actor warmstart**；mean MLP更新确实发生过。既要考虑学习步数不足，也要考虑微小更新破坏已有接触稳定区，不能只继续降低学习率或增加总法向力。

## 2. 本阶段目标与边界

保留固定67mm球形果实、原动力学、原五指PAD及严格G2。重点是拇指＋至少两个不同非拇指真正参与合围，改善建立时间、保持余量、重复reset和抗力/力矩能力。

允许新版本自主修改：reset初始化/缓存处理、动作滤波和有依据的动作表达、合理观测/历史、奖励、优化超参、归一化处理、训练课程、评估/记录实现缺陷、准备期姿态与支撑退出课程。所有条件变更明确记录，重做同条件对照；正式验收支撑6秒后必须实际为零。不得以“修复评估”为名放宽成功标准。

不包含：重标/扩大PAD、隐形固定与回合内状态写入、改变质量摩擦或提高物理驱动上限以过关、上游环境修改、提举/机械臂运动、广泛泛化和真机。旧版、F2、v2.2及原始失败不修改。常规技术决定不逐项询问用户。

## 3. 执行阶段

|阶段|核心工作|最小产物及转向依据|
|---|---|---|
|A 接收与隔离|核对输入，创建新根和源码；先修正启动器固定路径、保护列表、版本和必要记录字段；保留模型与normalizer语义|RECEIPT.json、BASELINE_LINK.json、源码版本、少量必要CPU接口/负例；不重做整套历史审计|
|B 建抓/重复reset诊断|同进程反复reset与独立进程重载分开；至少观察4env的多轮真实建抓，比较首次与后续reset；检查root/dof速度、target、滤波与历史缓存及settling|RESET_DIAGNOSIS.json；支撑退出前后最弱指力、几何、速度、动作差和首个失效因素；没有证据不强行修改reset|
|C PPO稳定性与有效训练|选择最有依据的1–2条线，轮内进行有意义的多update训练；保留更新前actor、normalizer、best/last和真实交互|每轮假设/配置/更新数、开发对照和失败原因；重点看同条件G2和早期建抓，不按reward选唯一best|
|D 抗扰课程|建抓稳定后依次2→3秒、低幅力→正式力、低幅力矩→正式力矩；维护旧quiet能力，避免只对单轴成功|quiet/force/torque独立成功窗及重载；训练低幅结果不能当正式幅值验收|
|E 新F4与封存|冻结候选、源码、比较actor、真实case调度；新20项正式比较、独立重载复测、开掌、两视角录像、必要核验|EVAL_TABLE、成功窗、可重载权重和源码、资源账、报告和manifest；成功或止损交付后停止|

主Agent统一源码合并、GPU锁和最终判定。子Agent A可只读诊断/独立分支修复reset与控制，B可准备PPO方案或核验；两者不得修改同一未交接文件，不各自抢跑GPU。无需为凑并发启动两人，任务合适时才派。

### 优先候选方向，按证据选择而非全部实现

1. reset真实状态、滤波/target/历史和settling一致性；修复只能在reset阶段正确建立初态，不能在已开始的抓取中扶正果实。需区分正常接触敏感性和程序缺陷。
2. 比较完整v2.2 actor＋normalizer迁移与常量先验；必要时以F2 actor作独立起点。完整warmstart、常量bias、strict resume必须分别记录，不能同名混用。
3. 保留先验的受约束PPO：先冻结编码层学习输出bias/critic，或限制actor相对teacher偏移/KL；检查normalizer漂移和确定性执行差异。若证据表明限制过强，再逐步解冻。不是预设有效。
4. 有意义的多update采样。可从20–50 update一段起步，按学习曲线调整段长/探索/LR，不受历史1 update约束；每5–10 update开发检查并留存，必要时延长。记录实际动作裁剪、最弱指力/份额、断窗因素及训练/确定性评估差距。
5. 围绕支撑交接前后连续性、第三指承载余量、对向几何、旋转/切向滑移作有界密集奖励；保持非PAD/故障/掉落正奖励屏蔽和过载惩罚。不得用更大总力代替真正合围。
6. 确有证据才加入局部接触历史、残差控制或动作重参数化；显式版本化、迁移和同条件初始对照。优先小而可解释的改动，不为实现复杂度而改架构。

## 4. 正式物理判据保持不变

同一个拇指＋两个非拇指组合连续360个真实120Hz子步（3秒）；各批准PAD≥0.15N且≥五指PAD总承载5%。NONPAD/掌承载为零，UNKNOWN/无效/漏步不通过，七类sticky硬故障均未触发。支撑实际力/力矩为零；果底离地>0.005m、相对速度≤0.05m/s、锚点漂移≤0.01m。

合格窗在撤支撑后≤60子步（0.5秒）开始；非拇指中心间距≥0.006m，拇指对向dot≤−0.3；相对角变化≤10°、角速度≤0.5rad/s。正式力0.10mg、力矩0.01mgR，手坐标±XYZ，子步180–191共12真实步施加；窗必须覆盖脉冲，不能扰动失败后重新起窗；恢复阶段从252子步起速度≤0.02m/s直至窗结束。quiet无测试扰动。以冻结contract和独立复算的具体索引为准，不能靠一帧的±1误差放行。

指肚几何仍用用户已批准区域及原完整网格分类器；0.5mm位置/边界不确定度不扩大。每个声称成功的窗既要数值复算，也要对其同一env/episode/组合/起止步的接触点重分类。训练方的streak、录像、退出码不替代这两项。

如需探索不同建立时间等指标，可作为独立诊断并单列，不能替换旧G2。出现新问题时优先解决建抓，不要求用户再次标定。

## 5. 公正比较与完成标准

开发可使用历史20项，但标为已见回归数据。候选选择后预登记新正式清单：每actor20个完成回合，8quiet＋6±XYZ force＋6±XYZ torque；实际改变reset顺序/案例编排或预先声明的种子，并确认执行器真正读取该清单。固定初态单换seed不叫泛化或独立分布测试。

至少比较：①本线PPO前初始化；②新PPO候选；③当前v2.2更新actor作接续参考；④旧v1.6经原语义适配作历史参考。所有actor在相同新条件下实测，不搬旧分数。接口改变时做透明适配，不能可靠适配的列NOT_COMPARABLE并保留至少①②的有效比较，不能据此宣称超过v2.2。开掌另4回合。

另做一次独立重载确认：预先固定一个小批，覆盖quiet/force/torque（建议每类4回合），对本线初始化与候选使用同样清单；必要时同步测v2.2参考。观察改善方向是否复现，不能只重播单个有利env。保持失败和UNKNOWN；最终清单看过后再改模型则新建一轮最终协议，不反复选中最佳还称独立测试。

**本任务理想完成条件**（低成功率仍可达，不要求10/20或统计显著性）：

- F3：quiet、正式force、正式torque各有真实有效3秒三指窗；对应能力在另一次独立重载中得到复现。
- PPO：新正式20项总成功数高于本线同条件未更新初始化，相对当前v2.2参考总体不退步；正式力矩至少1个成功。独立重载确认批中，候选相对初始化的总改善方向再现。只称小样本实际改善，不宣称高可靠性。
- F4：比较分母完整，所声称成功逐窗核验通过、两视角录像及权重源码可重载、旧版哈希未变、交付材料完整。

更高成功率是加分，达到上述边界后封存即停止。若只有三指物理能力、初始化收益或F4复核完成，但PPO没有改善，明确记“部分完成，学习收益未建立”。如果正式成绩比初始化高但没超过v2.2，可报告此范围，不冒充接续版本全面提升。若比较不可比，保留新能力但不据此将目标标为全部完成。

## 6. 有限探索与自主持续规则

“一轮有效方案”指一个有明确假设、冻结版本/条件、实际PPO训练和同条件开发对照的实质方案；可含多个训练段、检查点和续训。小修或重试不人为拆成新轮，实质换奖励/控制/初始化假设则计新轮。基础设施失败单独计数和记账，不冒充学习负结果。

默认最多8轮；第4轮集中检查方向，允许自主转向，不用等用户回复。若第8轮时最近3轮内仍出现可重算物理进展，可写明证据后自主延长一次至总计最多12轮。无第二次延期，不以换run名、换seed规避上限。连续4轮无客观物理进展，提前暂停。

客观进展包括：配对开发G2成功增加且重载复现、新正式扰动模式成功、重复reset后合格建抓比例改善且保持故障不增。尚无G2时可用合格窗长度/早期三PAD建立的重复性进展决定是否换方向，但单次峰值、reward、准备期接触或参数改变不支持延期。轮内长期平台需诊断、停止或换假设，不能以“本轮尚未结束”无限续训。

GPU小时数和update数不设机械硬上限；每段完整记账，合理增加采样，不因上轮的小预算提前否定多update训练。上限约束探索方案和无进展行为。基础设施阻碍最多3个有区别的修复周期仍无法获得必要物理运行时，保留阻碍和可继续内容并暂停；不靠无差别重启累积周期。

达到理想目标→完成F4和交付后停止。到轮数/平台/阻碍边界→停止新探索，保存best与last，尽可能完成有限的现有候选复核和材料整理，按用户授权暂停目标，等待进一步指示；不能把暂停写成目标完成。不必为了没有成功的模式反复录成功视频，失败录像和明确NOT_RUN也可交付。

## 7. 最终最小交付

统一报告、阶段完成状态与停止原因；真实源码快照/commit和输入身份；初始化、best、last权重及normalizer；复现命令/版本依赖；全部实验和中断索引；完整对比表；每个声称成功的原始窗、数值报告及完整网格重分类；前/侧录像；SHA256 manifest及旧版未变复验；真实更新数/transitions、运行墙钟和失败重试账；下一项最有价值的未执行实验。

证据大文件可以留在新根并给明确索引，用户能访问即可；如交异机需实际拷贝，不能把本地索引叫成完整可移植包。无需反复扫描全部旧盘、增加复杂LP前置审计或重建无关工程。发现真实正确性问题必须修复，必要负例测试和成功窗核验不可省。
