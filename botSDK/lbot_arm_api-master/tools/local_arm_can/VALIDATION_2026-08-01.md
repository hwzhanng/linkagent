# 本机直连 CAN 真机验收记录（2026-08-01）

## 验收对象

- 机器人：Linkbot A7_V2 双机械臂。
- 当前末端灵巧手均未连接，本记录只涉及机械臂。
- 左臂：本机 `can0`，1 Mbit/s，关节 ID `0x3D～0x43`。
- 右臂：本机 `can1`，1 Mbit/s，关节 ID `0x33～0x39`。
- J1～J5：经典电机协议；J6～J7：Motorevo 协议。

## 链路与协议结果

1. 两个 USB-CAN 均由 Linux `peak_usb` 驱动识别。
2. 左右臂在相同遥测流程下均持续 7/7 健康。
3. 两条总线均为 `ERROR-ACTIVE`，`tx/rx error=0`，未发生 bus-off。
4. 在线判断不依赖握手回复，而使用持续关节状态帧。
5. J1～J5 通过 `0x95 + float32(20.0)` 设置 20 ms 自动上报。
6. J6～J7 通过 `FF FF FF FF FF FF FF FA` 以 50 Hz 查询状态。

右臂最初仅显示 J1～J4，并不是 J5～J7 硬件损坏。给 J5 初始化自动上报、
持续轮询 J6/J7 后，右臂稳定恢复 7/7。

## 使能与回零验收

“回零”指平滑移动到七关节 `[0,0,0,0,0,0,0]`，没有发送会重定义编码器
零点的校零命令。使能顺序为：全部失能 → 控制模式 4 → 全部使能。

| 机械臂 | 回零前最大位移 | 时间/控制点 | 最终最大零位误差 | 结果 |
|---|---:|---:|---:|---|
| 左臂 | 13.803° | 2.761 s / 139 | 0.055° | 通过 |
| 右臂 | 9.329° | 2.000 s / 100 | 0.033° | 通过 |

回零过程使用 50 Hz 五次平滑曲线，单关节位移硬上限为 20°。

## 当前安全边界

- HTTP 控制服务仅绑定 `127.0.0.1`。
- 使能和位置指令需要按机械臂分别提交物理区域确认字符串。
- `commission.py` 的运动命令还要求显式确认区域清空和急停复位。
- 任一关节状态超过 250 ms 或缺失，服务拒绝使能与运动。
- 失能/急停不需要区域确认，确保故障安全路径始终可用。
- 原厂高层 MoveJ 规划器没有猜测实现；`/right/movej` 明确返回失败。
