# LinkBot 双臂双手 Sim2Real 实测方案

实验日期：2026-07-27

## 当天必须完成

1. 左右手整机质量、转接件质量、线束随动部分质量。
2. 左右手安装后的重心近似位置。
3. 左右手 16 个独立通道的位置方向、零位、行程和重复性。
4. 灵巧手空载低速往返、三档速度阶跃、三档电流/转矩限制测试。
5. 五指法向压力、切向力、方向和滑移的原始值—物理量标定。
6. 双臂 14 个关节的 SDK 正方向、零位、静态偏置和低速正反向扫描。
7. 机械臂小幅阶跃响应、状态延迟和跟随频率。
8. `L8/R8 -> hand_base` 安装变换的实际尺寸复核。

## 安全前置

- 工作区清空，先确认急停、软件限位和网络断开方法。
- 首次只允许单关节、小幅度、最低速度；方向确认后再扩大范围。
- 机械臂不得在奇异位形、机械限位附近或可能撞台的位置辨识。
- 灵巧手测试不得让手指互撞；有外载时使用软限位和易脱落夹具。
- 每组试验前记录温度；电机明显升温、报警、异响或振荡立即停止。
- 禁止用手直接对抗正在闭环运动的机械臂或手指。

## 设备清单

- 0.1 g 或更好精度的电子秤；
- 游标卡尺、直尺、水平仪；
- 量程合适的推拉力计；没有时可用已校准电子秤完成法向测试；
- 测切向力的推拉力计或弹簧测力计；
- 两根等长细线和计时工具，用于双线摆惯量测试；
- AprilTag/标定板与固定相机，或三坐标/测量臂；
- 不同表面试片：橡胶、塑料、果皮近似材料；
- 软质假果实、真实目标果实及果梗样本；
- 急停可达，现场至少两人。

## 0. 会话基线

填写 `session_manifest.template.yaml`：

- 左右手序列号、硬件/固件版本、CAN ID；
- 双臂型号、控制器/SDK 版本、树莓派版本；
- 转接件、触觉片、护套和线束安装状态；
- 环境温度、供电电压、采样软件版本；
- 实际平均反馈频率和最大连续丢帧时间。

设备冷机静置 30 秒，再空载记录 30 秒。当天结束时重复一次，用于判断温漂。

## 1. 灵巧手刚体参数

### 1.1 质量

分别称量：

1. 裸手；
2. 手 + 触觉传感器；
3. 手 + 传感器 + 转接件；
4. 实际随手运动的线束；
5. 完整末端总成。

每项放置三次，换方向重复，记录均值和标准差。

### 1.2 重心

用两条不同支撑线/刀口测量投影重心，至少得到相对 `hand_base` 的 XYZ。无法完整
测量时，先得到沿手掌长度和厚度的两个方向，剩余方向在仿真中扩大随机化范围。

### 1.3 惯量

优先对完整末端做双线摆：

- 记录两根线间距、线长、摆动轴和 20 个周期总时间；
- 每个轴重复 3 次；
- 保存现场照片，明确末端姿态和摆动轴。

如果当天无法完成，质量和重心仍是 P0，惯量可先由 CAD/平行轴定理近似并随机化。

## 2. 灵巧手关节辨识

每只手的 16 个独立通道逐一测试，其他关节保持安全张开位。每条记录使用
`hand_joint_system_id.template.csv`。

### 2.1 方向、零位和行程

- 从安全中位开始，先增加 3% 命令，再减少 3%；
- 确认正方向和反馈方向；
- 缓慢到达软件安全上下限，不撞机械限位；
- 每个关节至少往返 3 次，记录回差。

### 2.2 低速正反向扫描

- 使用约 10%、20%、40% 安全速度；
- 在行程中间 60% 范围做三角波；
- 每档速度正反向各 3 次；
- 记录位置命令、位置反馈、速度反馈、电流、温度和故障码。

有电流—力矩比例时拟合：

```text
τ - τ_gravity = b*qdot + τ_c*sign(qdot) + τ_offset
```

没有比例时只能得到 `b_current` 和 `coulomb_current`，单位为原始电流值，报告中不得
写成 N·m·s/rad 或 N·m。

### 2.3 小幅阶跃

- 在行程 30%、50%、70% 位置附近测试；
- 幅度先用总行程 2%，确认稳定后可到 5%；
- 速度/电流限制使用低、中、高三档；
- 每个条件重复 5 次；
- 阶跃前静止 1 秒，阶跃后至少记录到稳定 2 秒。

输出：命令延迟、上升时间、超调量、稳定时间、稳态误差和峰值电流。

### 2.4 迟滞和死区

- 在中位附近做逐级增加的小命令，直到反馈开始变化；
- 正反两个方向分别测；
- 至少在 3 个关节位置重复；
- 得到位置死区、方向相关回差和最小有效命令。

## 3. 五指触觉与接触

使用 `tactile_contact_calibration.template.csv`，每根手指单独完成。

### 3.1 法向

- 指尖以固定姿态接触力计；
- 载荷点建议为 0、0.5、1、2、3、5、7、10 N，不能超过硬件安全值；
- 每个载荷保持 2 秒并重复 3 次；
- 同时保存完整点阵，不只保存总和/最大值。

### 3.2 切向与方向

- 固定法向载荷 1、3、5 N；
- 沿传感器局部 `+X/-X/+Y/-Y` 施加已知切向力；
- 每个方向至少 5 个力级；
- 记录传感器方向原始值，检查不是恒为 0；
- 用现场照片注明传感器坐标系。

### 3.3 滑移

- 选择橡胶、塑料、果皮近似材料；
- 缓慢增加切向力直到首次宏观滑动；
- 记录滑移前 1 秒和滑移后 2 秒完整点阵、法向、切向与方向；
- 每种材料/法向载荷重复 5 次。

输出：每指点阵标定、饱和值、噪声、漂移、切向方向偏差和滑移阈值。

## 4. 机械臂参数

每次只运动一个关节，使用 `arm_joint_system_id.template.csv`。

### 4.1 坐标与零位

- L1–L7、R1–R7 各做一个小正命令和小负命令；
- 同时记录 SDK `q/qdot/torque/current` 和仿真预期方向；
- 建立明确的 14 关节符号表，不凭视觉记忆。

### 4.2 静态与重力

- 空载及完整灵巧手负载分别测试；
- 每臂选择至少 10 个安全姿态，静止 3 秒；
- 记录位置、力矩/电流、温度；
- 使用 SDK 的工具重量/重心配置前后各采一组。

输出：工具载荷修正、重力模型残差和关节静态偏置。

### 4.3 低速恒速扫描

- 每关节在安全中间行程以正反方向恒速运动；
- 建议从 0.05、0.1、0.2 rad/s 开始，稳定后再加档；
- 每档正反向至少 3 次；
- 同时记录 `q_cmd/q/qdot/torque/current`。

输出：各关节粘性阻尼、库仑摩擦、方向不对称和速度死区。

### 4.4 阶跃/扫频与通信延迟

- 小幅位置阶跃，先 0.01 rad，稳定后最大 0.03 rad；
- 跟随模式分别测试 50、100、200 Hz；
- 主机命令和状态均记录单调时钟；
- 统计命令到运动开始的延迟、抖动、丢帧、超调和稳定时间。

不要用大阶跃辨识真实闭环增益；控制器内部参数未知时只能拟合等效闭环模型。

## 5. 安装与环境参数

- 测量左右 `L8/R8` 法兰到手掌基座的 XYZ；
- 用标定板或已知姿态求 RPY，至少验证当前 `±π/2` 镜像关系；
- 测量桌面、相机、种植架相对机器人 `base_link` 的变换；
- 称量典型果实，测直径、表面材料和果梗断裂力/扭矩；
- 每种目标至少 20 个样本，用分布而不是单一平均值进入训练。

## 当天结束验收

- 每个数据文件都有 manifest、单位、关节名、手侧和试验编号；
- 时间戳严格递增，没有整段常数或明显截断；
- 记录实际采样频率、掉帧、温度和异常；
- 原始 CAN/SDK 数据只追加、不覆盖；
- 现场照片与数据使用相同 trial ID；
- 立即复制一份只读备份。
