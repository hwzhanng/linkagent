# Sim2Real 参数准入

本文的严格条件只适用于“动力学敏感策略直接迁移真机”，不用于阻止仿真原型。
没有外部测量设备时，按照
`../../simulation_baselines/tomato_pick_v1.yaml`
进行宽域随机化，可立即开始环境与规则策略开发；但 PPO 必须等规则策略准入通过。
必须保留“不可直接下发真机”和“不可把点阵权重或名义量程解释为绝对力”的标记；
实机逐指力在完成标定前一律视为无效。

## URDF/USD 更新前

- 一只同批次代表手的完整末端质量误差不超过测量均值的 2%，右手按用户授权继承；
- 重心三个方向均有测量值或明确随机化范围；
- 14 个臂关节、32 个手指独立关节方向表完成；
- 所有物理量明确 SI 单位，原始 0–255 值保留在独立列；
- 电流—力矩系数未知时，不生成带 N·m 单位的摩擦参数。

## Isaac 接触训练前

- URDF 已成功转 USD，46 个独立 DOF 与 10 个 mimic 约束核对；
- visual 与训练 collision 分离；
- 指尖碰撞体通过已知球/平面接触检查；
- 仿真触觉代理可复现；真实逐指法向、切向和滑移标定列为部署硬门禁；
- 机械臂、手指驱动增益没有静止振荡；
- 质量、摩擦、阻尼、时延和传感器噪声都有 domain randomization 范围。

## 真机闭环前

- 仿真与 SDK 每个关节同方向、同零位、同弧度；
- 安装变换、桌面和相机外参完成；
- shadow mode 回放不下发真机，动作限位全部通过；
- 碰撞距离、关节速度/加速度、指尖压力和急停监控启用；
- 至少完成 100 次仿真随机化评估和低速空载真机回放；
- 接触策略先在软质假果实上通过，再接触真实农产品。
