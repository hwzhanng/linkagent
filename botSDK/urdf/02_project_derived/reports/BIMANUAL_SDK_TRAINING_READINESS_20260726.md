# SDK 双臂双手模型与仿真训练就绪度

日期：2026-07-26

## 结论

已经可以进入 Isaac Sim 的第一阶段工作：URDF 导入、可视化、运动学检查、关节空间
控制、无接触轨迹回放和农业抓取任务框架开发。

目前可以开始接触环境和规则策略开发，还不能把策略直接迁移到真机。左手速度、延迟、
双向死区和安全命令范围已经实测；右手直连、触觉和左手标定继承仍待验收。矩阵触觉
只有 `0..255` 相对权重，名义 `20 N` 量程不是 raw→N 换算曲线。剩余主要缺口是灵巧手
质量/惯量、真实关节输出力矩、阻尼/摩擦、驱动增益、触觉标定和果实接触参数。

## 来源与方向保证

机械臂直接取自随设备交付的 SDK 控制平台模型，不取在线网页仿真模型。自动逐节点
对比确认 17 个 arm link 和 16 个 arm joint 的坐标、关节轴、限位、质量及惯量全部
保持 SDK 源值；17 个 arm STL 哈希也一致。

左右手分别与项目使用的 2024 厂商 L20_8 源模型逐节点一致。右手继续使用已经确认
的安装：

```text
R8_Link -> right_hand_base_link
xyz = (0, 0, 0)
rpy = (π, 0, +π/2)
```

左手按要求做严格 yaw 镜像：

```text
L8_Link -> left_hand_base_link
xyz = (0, 0, 0)
rpy = (π, 0, -π/2)
```

这里“镜像”已经通过数值检查，但零平移仍来自现有装配定义，并非用标定板测得的
六维法兰变换。

## 已补齐内容

1. 机械臂源路径改为归档的 SDK 交付模型，避免网页可视化资产将来变化。
2. 厂商仿真起始值写入 14 个机械臂关节：
   `damping=20`、`friction=0`。这些值已在 URDF 注释和配置中标记为非实机辨识值。
3. 保存 Isaac 导入基线：固定底座、不合并 fixed joints、凸分解碰撞、关闭全局
   自碰撞、位置求解迭代 8。
4. 保存机械臂位置驱动起点：`stiffness=2000`、`damping=20`。
5. 保存 SDK 状态与控制频率信息：状态 50 Hz，跟随指令 50–200 Hz。
6. 保存双臂、双手独立控制关节分组和安装变换。
7. 完成实机左 G20 的 468 条基础运动、192 条高速运动、100/100 条 80% 热稳态
   可靠性和 80 条中位双向死区试验；最高 55°C，CAN TX/RX error 和运动后故障均为 0。
8. 将左手实测速度、死区和碰撞安全 raw 范围写入 URDF 与独立控制器覆盖层；右手
   保留厂商值并标记待直连验收，不能把同型号当作已经验证。

没有补写无法由运动反馈推出的手指真实转矩、阻尼、摩擦、软指尖材料和完整手掌惯量。

## 训练缺口与补齐方法

### P0：接触强化学习前处理

1. **扩展 Isaac 接触测试**
   - 基础导入和无接触动态冒烟已经通过；
   - 下一步加入桌面、果实和指尖接触，检查碰撞近似、穿透和接触稳定性；
   - 用标定后的窄横摆范围验证自碰撞过滤与 coordinated pose。

2. **重做训练 collision**
   - 当前 collision 直接复用了 125.6 万面 visual STL；
   - 机械臂和手掌采用凸包/凸分解；
   - 五个指尖单独制作低面数且曲率准确的碰撞体；
   - 保留 visual STL 只用于显示。

3. **修正灵巧手质量**
   - 厂商公开整手重量约 1 kg，但当前左右 URDF 分别仅约 0.198 kg；
   - 对安装了触觉片、线束和转接件的整手称重；
   - 至少测量整手重心，最好用双线摆或 CAD 取得惯量；
   - 在测量前对手部质量、重心和惯量做较宽 domain randomization。

4. **补完手指执行器动力学**
   - 左手 16 个命令通道的速度、延迟、raw 死区和安全范围已完成；
   - G20 不回传真实电流，SDK torque 是最大限制而非测得力矩；
   - 用推拉力计、已知力臂和同步位置数据拟合输出力矩、粘性阻尼、库仑摩擦和迟滞；
   - 右手可以用左手参数作为仿真随机化中心，但直连控制、方向、速度和触觉仍需复测；
   - 在辨识前不要把 URDF 中 `effort=100` 当成真实 100 N·m。

### P1：农业抓取接触训练前处理

1. 用测力计/电子秤做指尖法向压缩测试，拟合软指尖刚度、阻尼和最大安全压力。
2. 用已实现的法向、切向和滑移数据标定 Isaac Contact Sensor 到 L20 点阵的映射。
3. 建立果实表面摩擦、柔度、半径、质量随机化；果梗需要断裂力/扭矩或柔性关节模型。
4. 由实际可碰撞组合生成自碰撞过滤表，不能永久依赖“全机器人关闭自碰撞”。
5. 加入 50–200 Hz 控制周期、网络延迟、观测噪声、丢包和动作限幅随机化。

### P2：策略上真机前处理

1. 左右机械臂逐关节小角度联动，核对 SDK 状态与仿真同向、同零位、同弧度。
2. 用标定板或手眼标定求出两个 `L8/R8 -> hand_base` 的实测六维变换。
3. 用安全笼、低速和软件限位进行 shadow mode；先只比较策略输出，不下发真机。
4. 通过碰撞距离、最大关节速度/加速度、最大指尖压力和急停条件后再闭环。
