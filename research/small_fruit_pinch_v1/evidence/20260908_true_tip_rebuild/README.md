# 64–70 mm 指尖首接触重构证据

日期：2026-09-08  
范围：仅左手、仿真、无 PPO、无实机命令。

## 当前结论

1. 旧候选的三指接触统计不能证明指尖首接触，人工否决成立。
2. 真实受力碰撞壳是拇指 `link4`、其余手指 `link3`；末端 `link5/link4`
   是毫米级固定标记，不能把传感器直接改绑到标记上。
3. 接触点轴向进度 `>=0.68` 暂作为仿真远端指垫门，不代表实机标定。
4. AABB 静态候选在动态真实网格中为零接触，不可晋级。
5. 固定 70 mm 并从两指邻域局部搜索后，独立关节瞬时探针已得到三指末端
   真实接触；六个近端传感器均为 0 N。较均衡样本约 `0.86/0.69/0.76 N`。
6. 瞬时构型尚不能晋级：连续执行时拇指没有形成稳态接触，食中指先接触
   后将果实推移。仅增大拇指远端不能补足；错误方向增大横摆会进一步远离。
7. 结论仍是暂不训练；下一步必须搜索“连续到达后的负载形变构型”，不能
   再把瞬时写入关节状态的接触当作可执行先验。

## 证据文件

- `physical_contact_cem_seed20260928.log`：512 环境、80 代真实 PhysX 接触搜索；
  最佳样本分别覆盖食中两指或拇中两指，无三指通过。
- `direct_joint_local_proximal_sensors_d70_seed20260932.log`：固定 70 mm、加入
  六个近端真实传感器后的局部搜索，产生三指瞬时末端接触。
- `direct_joint_trajectory_probe_long_d70_seed20260933.log`：同步末端闭合的连续
  路径；食中指稳态接触，拇指未接触。
- `direct_joint_trajectory_thumb_lead_d70_seed20260933.log`：拇指远端提前路径；
  仍未形成拇指稳态接触，排除“只改时序即可解决”。
- `direct_joint_trajectory_thumb_reach_d70_seed20260933.log` 与
  `direct_joint_trajectory_thumb_sweep_d70_seed20260933.log`：横摆方向消融反例。
- `../20260907_physics_direction_probe/VISUAL_REJECTION_20260907.md`：人工视觉
  否决及硬门定义。

## 下一继续门

- 拇指横摆与末端卷曲可独立控制；
- 连续执行而非瞬时写入时，三指真实末端区域同时接触；
- 非末端首接触为零；
- 食指—中指支撑点至少 20 mm；
- 拇指—食指表面裕量至少 2 mm；
- 连续轨迹先完成对向/展开，再同步闭合指尖。
## 2026-09-10 动态教师与候选训练补充

- `dynamic_contact_cem.py` 已加入连续驱动搜索，但当前预对向阶段会把指间几何带离果实，420 步末段三指力为 0 N，见 `dynamic_contact_cem_d70_seed20260940.log`。
- 为验证是否只是执行器努力上限导致，新增 `--hand-effort-limit`，并以 0.2 的显式 PD 上限进行了 5-update 候选训练；候选仍为 0 接触、0 成功率，不能作为人工验收权重。
- 当前结论：问题位于“果心初始化/预对向目标/接触前轨迹”的联合几何，而不是单纯力矩或压力阈值。旧权重与本轮 pilot 均保持只读，不覆盖历史成果。
