# 小果捏取候选审计（2026-09-10）

## 结论

本轮不发布新 PPO 权重。此前“静态有效候选”不能作为训练种子或成功证据，原因是扫描器的
指尖几何索引与动态执行链不一致；修复索引后，连续 PhysX 教师仍未形成三路有效指尖接触。

## 证据

- 修复前局部扫描曾报告 `valid=6273`，但动态执行中三路末段力为 `0 N`，指尖距果心约
  `65–72 mm`。
- 扫描器已改为使用与传感器相同的 articulation body id；修复后放宽门的
  `80×1024` 搜索仍未得到可直接发布的候选。
- 显式教师在固定果心、目标误差约 `0.008 rad` 时，末段有效力仍为 `[0,0,0] N`，说明
  关节写入虽然到位，但候选中心/指尖刚体几何不匹配，不是“把压力上限调宽”即可解决。
- `test_temporal_and_verifier.py`：4 passed；源码编译与 `git diff --check` 通过。
- 短程 actor-init 训练已完成 8 updates × 128 env，权重为
  `logs/rsl_rl/small_fruit_pinch_v1_thumb_alignment_probe_20260910/model_final.pt`；训练日志中
  `contact_ratio=0`、`success_rate=0`，故明确标记为失败样本，不作为人工验收权重。
- 以既有 `model_150.pt` 直接续训 3 updates 的复核也得到 `contact_ratio=0`、
  `success_rate=0`；这排除了“仅需更多 PPO 更新”的解释，说明当前严格环境合同与旧权重的
  几何/初始化不兼容。

## 当前不足

1. 静态候选仍混用 AABB clearance 与真实指尖刚体中心，几何门只能用于筛选，不能替代接触验证。
2. 动态教师需要先用同一环境 FK 反解果心，再逐步闭合；目前预对向目标仍可能把指尖带离球面。
3. 还没有满足“三指有效指尖接触、近端零受力、正 SAT 裕量、连续保持”的回放，因此不能训练
   或导出看似成功的 PPO 权重。

## 后续执行顺序

1. 新增统一 FK/坐标回归：同一组 `pinch_action_to_joint_targets` 同时打印五指真实刚体位置、
   果心和接触壳距离，禁止局部索引复用。
2. 在真实 body FK 上联合搜索果心、拇指横摆和食/中指根部，先满足末端表面距离，再加入
   近端禁触、拇指对向角和食中支撑跨度。
3. 对候选执行固定步长的“根部预对向→拇指横摆→食中协同→远端微调→保持”，每阶段记录
   首接触顺序、接触点轴向进度、力峰值与自碰撞裕量。
4. 仅当至少 3 个独立 seed 通过动态门后，才启动短程 PPO；旧 89% 权重和本轮 pilot 继续只读封存。

1. 指垫碰撞壳与 link3/link4 的真实几何仍未回归，近端先接触风险无法由动作奖励单独解决；

否则只标记为诊断候选，不覆盖既有成果。
