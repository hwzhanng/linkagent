## 2. 环境与动力学

| 项目 | 当前设置/口径 |
|---|---|
| 机器人 | 单只右L20、固定腕部、16主动关节+5 mimic从动关节 |
| 物体 | 接触仿真的单个果实近似刚性椭球；未建模组织变形或瘀伤 |
| 物理步长 | 1/120秒 |
| 控制降采样 | 每6个物理步控制一次，即20Hz |
| 回合 | 配置24秒；当前时限实现通常记录479个控制步，即23.95秒 |
| 控制 | 16维关节目标增量，动作截断[-1,1]；每步目标增量上限0.035rad，目标相对当前关节领先上限0.11rad |
| 抓取初始化 | JSON候选姿态经真实PhysX筛选；每运行记录文件路径与SHA-256 |
| 物理终止 | 中心偏离>0.105m、指尖法向力代理>8N、压力代理连续3步>18kPa、物体高度<0.78m或位置非有限 |
| 平放姿态 | 根位置(0,0,0.90)m；XYZW四元数(0,-√0.5,0,√0.5)，检查掌面局部+X映射到世界+Z |

不同随机化profile：

- `nominal`：三轴半径均0.032m，复位关节/位置噪声为0；**并非完全确定性或零随机化**，质量/密度、观测噪声、稀疏面板缺失等仍存在。
- `gentle`：半径各0.0315–0.0325m，关节噪声标准差0.004rad，位置噪声0.00025m。
- `full`：半径各0.029–0.035m、轴比约束≤1.20，关节噪声0.018rad，位置噪声0.002m。
- 密度850–1050kg/m³、可接受质量0.08–0.19kg。v7训练实际保存的质量约0.1167–0.1441kg；配置中保留每个环境的实际几何和质量，不能把名义范围当作已测分布。
- 压力噪声比例0.025、触觉噪声比例0.035、稀疏面板缺失概率0.25；均属于工程仿真假设。

资产、摩擦、接触顺应、求解器配置的准确值以各运行`source_snapshot/env_cfg.py`及生成资产manifest为准。[当前环境源码](../../../simulation/roto2_pressure/env_cfg.py)不是旧实验所有版本的替代品。

## 3. 观测、网络与压力修正

每帧502维：

| 组成 | 维数 |
|---|---:|
| 五指12×6触觉网格 | 360 |
| 六面2×2稀疏压力 | 24 |
| 稀疏压力差分 | 24 |
| 稀疏有效位 | 24 |
| 关节位置/速度 | 32 |
| 接触中心、面均值、中心速度、面通量 | 15 |
| 重力、目标轴、目标速度 | 7 |
| 上一步动作 | 16 |
| 合计 | 502 |

其中prop70、tactile432，4帧后分别280、1728，总2008。Encoder隐藏层512/256，ELU与LayerNorm；策略和价值网络隐藏层128/64。沿用同一个上游PPO实现，没有新增非对称特权critic输入或额外神经动力学模型。

Actor观测只由本体、触觉、稀疏压力及其衍生量构造。真实果实姿态、全表面96点压力代理用于任务奖励/评估等仿真计算；局部旋转响应估计也使用仿真运动，**这部分不能直接视为已经能无修改部署到真实硬件**。

压力Jacobian估计为24×16。小幅残差通过任务方向约束及接触/有效面板等门槛决定接受与否；当前奖励没有正的“压力下降奖金”。稀疏压力/全表面压力来自真实仿真接触力经高斯分布映射，尚非已标定的实体薄膜压力，更不是实际水果损伤测量。

本轮v6/v7前后[架构检查](evidence/simulation/.runtime/setup/rotation_v7/architecture_check.json)证明相对各轮前快照的核心构建和关键环境函数未变。整个本地开发周期中确有物理适配、接触映射、复位、奖励及评估代码修复，不能泛称“从远端初始提交起所有底层文件都没改”。

v7实际31,999,440新增转移、61次PPO更新，三个模块有参数变化并保持有限。v6实际63,998,880、122次更新。环境扩容提高吞吐，但每百万样本更新次数与256环境阶段不同；不能仅按“训练M步”推断学习是否足够。

原始TensorBoard是低频评估/汇总日志，不是每步学习数据。部分tag是回合累加量，例如`rotation/secure_grasp=444`表示支持步数累计，**不能直接读成444%的承托率**。独立评估JSON的fraction字段才是相应归一化统计。`step`通常是新增训练转移计数，首条可能对应刚复位的短片段，不能将step0回报与完整24秒回报直接比较。

## 5. 奖励版本与v7公式

v2–v5用真实姿态和有效触觉逐步修正、引入接触课程；准确版本以每运行源码快照为准。v6新增`regrasp/spin`：20倍有符号姿态增量，允许两指推进，严格三指时发一次性里程碑，EMA承托缺失罚项。v7新增独立`continuous`分支，不覆盖旧函数。

令`d=sign(goal)×Δθ`；`full`为拇指+至少两根其他手指有效承托且倾斜合格，`drive`至少拇指+一指且物体未过度偏移。v7主运动项：

```text
r_motion = 20 × min(max(d,0), 2×|goal|×dt)
                 × (0.25 + 0.75×full) × ready × valid × drive
             + 20 × min(d,0) × ready
```

`ready`排除首1秒，`valid`保留姿态连续性和压力合格路径。其他项：

| 项目 | 每步系数/形式 |
|---|---|
| 缺少严格三指 | -0.15 × (1-full)，首秒后 |
| 区域外接触 | -0.06 × 有足够原始力但非有效pad的指尖连杆数 |
| 抓姿偏离 | -0.05 × Σ(q-q_reset)² |
| pad quality / approach | 各0.04×(质量-1) |
| 中心位移 | -0.04×clip((位移/0.05)², max=9) |
| 倾斜 | -0.10×tilt² |
| 动作差分 | -0.006×mean((a-a_previous)²) |
| 时间 | -0.025 |
| 无效姿态/压力路径 | -0.20 |
| 压力风险 | 非plain模式另扣0.05×measured_risk |
| 物理失败终止 | 非contact阶段另扣60；超时不按物理失败罚 |

v7仍用正向0.15–0.30rad/s课程，以隔离奖励变更；v5普通旋转/后续spin使用更高目标范围及双向。两指最大正运动信用0.15，立即承托代价已抵消它，因此长期两指无法赚取正总奖励。但这并不保证策略能发现好的换指动作，也未证明全部折扣摆动漏洞被消除。

## 6. 独立评估

每个固定评估种子64环境；每环境只统计第一个完整回合，以首次终止mask排除自动复位后的新回合。评估动作确定性，但物理参数和噪声仍按profile存在。两个评估种子不等于两个独立训练种子。

完整成功必须同时满足：

1. 按目标方向，实际四元数重构的净旋转≥1圈；
2. 严格有效承托下取得的新增历史最高进展≥1圈，重复往返不重复计功；
3. 严格三指承托率≥65%，正立比例≥95%；
4. 无物理失败、压力代理不过18kPa、无单步姿态角度跳变≥0.5rad。

小角度课程条件是排除首秒后≥30°、三指≥50%及其他安全/姿态约束；这不是完整成功。v6只有15/128满足，因此spin阶段没有执行。

新增诊断包括10秒后净推进、分指pad接触、关节距限位、原始力与区域外接触、支持恢复事件。恢复事件只是便于比较的诊断定义，不能取代真实录像或完整任务验收。

[eval JSON](tables/evaluations.json)保留每份文档自己的`success_definition`和有效性标签。没有明确真实姿态依据的旧文档标为legacy/unverified；错误四元数初始化独立标为rejected。历史源码快照、旧报告和旧成功字段出现在文件包中，不代表这些结论重新有效。

## 7. 仍缺的实验

- 在相同预算、多个训练种子下比较plain/scalar/jacobian，并匹配旋转性能后比较压力。
- 学会基本循环后再进行双向、几何/质量随机化与扰动鲁棒性验收。
- 对真实传感器区域、力/压力代理和刚体接触模型进行标定。
- 实体薄膜压力及延迟瘀伤实验；当前没有相关数据。
- 检验回退/重抓在现有握姿下是否具有足够可达动作空间，见[后续计划](NEXT_EXPERIMENTS.md)。
