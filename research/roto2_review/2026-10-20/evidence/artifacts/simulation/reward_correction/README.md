# 手内转动：奖励修正与重训

**当前状态：奖励和计分漏洞已修正，行为尚未验收，追加训练运行中。旧版72.4%成功率已撤回。**

## 确认的问题与修正

1. 旧模型的角速度积分与实际四元数姿态变化不一致。一个10秒样本的旧积分为2.426圈，而实际姿态增量约−0.00291圈。现在奖励、评估、视频都以实际姿态为依据，并用独立SciPy四元数计算交叉核对。底层速度报告异常的具体原因尚未完全解释，未改物理求解器。
2. 旧触觉映射把指尖刚体的区域外接触截入阵列，将壳体/背面接触误当作触觉区域。现在按有效区域及深度筛选，区域外不产生触觉阵列读数。区域是依据厂商传感器盖网格拟合的仿真近似，尚无实机标定。
3. 正向转动奖励要求拇指和至少两根其他手指在有效区域承托，只奖励目标方向首次达到的新转角；静止、反向回摆、重复旧转角、姿态突跳不能刷正向分。取消正向卸压奖金，保留压力风险罚项。
4. 加入指腹接近/朝向的连续奖励和独立接触课程。接触课程允许奖励稳定有效抓握，但最终转动验收仍要求真实旋转。

## 核心架构边界

RoTO2 Encoder、策略/价值网络、PPO/GAE/优化器实现、70维本体+432维触觉输入、四帧堆叠、16维动作和压力Jacobian修正算法保持不变；上游源码工作区干净。未改碰撞几何、求解器或执行器参数。

明确调整了奖励、触觉有效区域、初始抓姿与随机化课程，以及两个训练超参数：初始探索标准差1.0→0.25、熵权重0.05→0.005。没有把物体姿态真值增加到策略输入。
