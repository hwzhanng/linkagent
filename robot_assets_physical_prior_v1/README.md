# LinkAgent 物理合理仿真先验 v1

日期：2026-09-30。对应仓库基线：`ac71d6bb3a65ca6f0add5599f766caf856716bb3`。

## 结论与使用范围

这是一套可安装、可回退的 **公开规格约束 + 明确工程假设** 资产候选，不是实测标定。
目标是在没有测量条件时，修复已证实的不一致，提供物理量纲正确、质量与惯量自洽、被动机构不独立供能的仿真起点。

- 给出完整的新 URDF，以及叠加到原 Physics-v1 USD 的物理参数层
- 接入 Physics-v1 / Physics-v2 的实际驱动配置和启动质量检查，避免仅改 URDF 而运行时仍覆盖为旧值
- 保留既有资产，默认行为不变；新资产通过独立环境变量启用
- 不替换已校正的机械臂坐标系、手部轴向、安装姿态或用户安全动作映射
- USD 仍继承仓库“单右手任务”的碰撞集合；不能把它宣传成完整双臂双手碰撞环境
- 没有运行完整 Isaac/PhysX、抓取策略或真机回归。缺少 GPU/Isaac 和原始大几何文件，不伪造通过记录

## 主要修改

### 1. 质量、质心和惯量

L20 V1.2 手册与当前产品网页均给出整手约 1.2 kg。本版采用每手 **1.2 kg**，整机器人资产总质量 **24.352354 kg**；每个安装转接件仍为 0.030 kg，独立于整手质量。

质量分组仍用既有工程分配：掌部 55%（0.660 kg）、拇指 13%（0.156 kg）、其余四指各 8%（0.096 kg）。这不是厂家公布的分件称量值。采用这一分配是为了保留当前结构先验，避免用缺乏依据的新分配替换另一套假设。

结构实体的惯量随质量同比缩放，保留 CAD 质心、主轴和回转半径。机械臂/底座质量、质心和惯量保持 SDK 值；来源一致和数学可行并不等于已标定。所有 71 个刚体重新用完整对称惯量张量生成 USD 主惯量/主轴，包含此前确认的主轴方向修复。

**额外修复：10 个固定指尖标记体。** 其可见 CAD 尺寸只有约 1–2 mm，旧工程模型却各给 10 g 并人为抬高惯量，无法满足该尺寸下的惯量必要条件。本版在整体放大到 1.2 kg 后，将这些标记体原来对应的约 12 g 质量转移到相邻实体末节，按父末节 CAD 形状同比增加惯量。标记体保留 1 mg、按其包围盒计算有限正惯量，坐标框架不删除，整手总质量不变。

这是重新分配质量的工程假设，不是“仅改表示、保持原聚合惯量完全相同”。标记体微小质量对 PhysX 固定连接数值条件的影响仍需完整引擎验证，不能用通过 MuJoCo 测试替代。

### 2. 力矩与速度

机械臂沿用 SDK 80 / 36 / 18 N·m 分组上限，**不声称这些是经核实的持续额定力矩**。工作速度限制为 1.5 rad/s，低于旧 URDF 的 7.33–10.47 rad/s。

主动手关节不再沿用统一 100 N·m。采用下列等效操作上限：

| 关节 | 力矩上限 N·m |
|---|---:|
| 拇指侧摆、旋转 | 0.25 |
| 拇指近端弯曲 | 0.40 |
| 拇指远端弯曲驱动 | 0.30 |
| 其余四指侧摆 | 0.15 |
| 其余四指近端弯曲 | 0.60 |
| 其余四指远端弯曲驱动 | 0.35 |
| 10 个被动跟随关节 | 独立驱动为 0 |

以上是按“小力抓取、厘米级力臂”的数量级选择的工程上限，**没有电机常数、减速比或逐姿态测力依据**。例如 0.4 N·m 配 50 mm 垂直力臂对应 8 N，但不能把这个例子推广为各姿态恒定指尖力，也不能据此保证峰值力不超过某个 N 值。多关节耦合、接触方向和接近奇异姿态都会改变力映射。

手指采用 1 rad/s 的保守操作速度，不冒充产品最高速度。驱动跟随联动时进一步限制为 `min(1, 0.95 / |mimic比例|)`。拇指联动驱动因此约 0.856 rad/s。

公开手册部分角度、速度与旧 CAD/已使用的动作映射有版本差异，不能无条件扩大行程。本版保留原机械坐标与限位，仅缩小与跟随关节冲突的驱动范围。

### 3. 被动机构

- 10 个 URDF mimic 偏置统一为 0，与当前 Physics-v1 的零偏置约定一致
- 保留现有 1.11 / 0.94 比例，作为线性连杆近似，而不是已标定的精确传动曲线
- 驱动全行程必须落在跟随关节可达范围内；拇指驱动上限由 1.32 收窄为约 1.2072 rad
- 两只手的 10 个被动关节均不独立驱动；USD 为左手补上与右手同型的 native mimic
- 被动约束仍可传递力矩；“驱动力矩为 0”不是禁止机械传力

### 4. 阻尼、摩擦、转子惯量与闭环控制

见 `joint_parameters.csv`，56 个自由度逐项列出 SI 参数。

机械臂：不再把 URDF 的统一阻尼 20 当成被测粘性摩擦。本版被动粘性阻尼为 0.06–0.25 N·m·s/rad、库仑摩擦为 0.09–0.40 N·m；等效驱动 P 增益为 60–600 N·m/rad，D 增益为 5–40 N·m·s/rad，附加关节惯量 0.01 kg·m²。

主动手关节：被动粘性阻尼 0.005 N·m·s/rad、库仑摩擦 0.003 N·m；等效 P=4 或 6，D=0.12，附加关节惯量 0.0002 kg·m²。被动跟随关节无 P/D 独立驱动。

**全部属于可耗散、有限的工程先验，不是恢复出的真实控制器参数。** 驱动 D 与机械摩擦不能混为一谈，不能把一次阶跃拟合拆解成唯一的真实摩擦值。

后端语义明确区分：URDF 的 `dynamics.friction` 在这里表示 N·m 库仑摩擦；旧 PhysX `physxJoint:jointFriction` 是无量纲系数，本版主动关节用 0.02、被动关节用 0.002。两者不是直接数值换算，MuJoCo 与 PhysX 的耗散并不严格等价。USD 驱动角度单位按 degree 转换，Isaac 配置使用 rad。

### 5. 接触

保留当前任务的指垫/果实静摩擦 0.55、动摩擦 0.45、average 合成，以及 5000 N/m、25 N·s/m 的等效接触弹簧/阻尼。它们没有本机测量证据，但具有正确量纲和正耗散性质。不能因为某篇论文的其他橡胶/品种摩擦均值是 0.305，就认定你的指垫也应改成该数。

提供静摩擦 0.3 / 0.55 / 0.8 等敏感性场景，不能把它们称为统计置信区间。`uncertainty_sweep` 是用于验证的配置清单，**没有暗中接入 PPO 自动随机化**。果梗断裂模型、奖励和成功判据不在本次机器人资产改动中；不会为了让抓取成功而降低断裂力。

## 验证结果和未通过的边界

已完成：

- 71 刚体正质量、正定惯量、惯量三角不等式检查
- 70 个关节的轴向、安装变换、父子连接与基线一致
- 10 组联动全范围和速度相容性检查
- 67 个可获得网格的质心包围盒、二阶矩必要条件检查；均通过
- URDF / USD 全刚体惯量张量复算，最大相对误差约 2.22e-7
- 500 个几何无接触姿态：完整质量矩阵正定；检查机械臂重力力矩
- 5 种工程场景 × 3 个种子 × 6 秒，独立 MuJoCo 惯性骨架闭环测试，有限状态、无求解器警告；末段最大跟踪误差低于 0.02 rad
- 6 个孤立斜面摩擦测试，与解析滑移方向一致。它验证测试模型的摩擦行为，不识别真实指垫摩擦
- 6 项接入单元测试、安装与回退、缺文件拒绝启动检查

**重要负面结果：** MuJoCo 骨架测试没有实现 PhysX 的关节硬速度约束，虽然目标已限速，实际瞬态速度仍超过目标上限；弱驱动压力场景出现约 9.3 rad/s 的瞬态。结果原样保留。因此不能将这些测试称为“速度安全通过”或“PhysX 驱动回归通过”。候选 USD 与 Isaac 配置均显式设置求解器速度上限，但实际执行效果必须在 Isaac 上验证。

未验证：

- 原始大 `geometries.usd` 以及四个大型手部 STL 没有在本云端取得，未伪造或替换
- 完整碰撞形状、穿透、自碰撞、抓取、接触压力、PPO 或 Isaac 大规模稳定性
- 真机批次、持续力矩、温升、反向间隙、自锁、真实摩擦与延迟

因此本包是**物理量自洽且有有限验证的候选起点**，不能写成“全部机器人行为已经确认正确”。

## 上一版修正包的接入更正

最终实际安装检查发现，上一版惯量修正包的 USD 叠加层没有显式声明 defaultPrim 和场景单位；USD 根层这些元数据不能依赖子层自动继承，直接作为机器人资产加载可能失败或使用错误的默认单位。本版已显式设置 defaultPrim、米、千克和 Z-up，并实际打开安装后的相邻层组合验证。请以本包为准，不单独启用上一版。此前惯量张量算法结论仍有效，但不能把此前数学检查当成资产入口加载成功。

## 安装与启用

在完整的原仓库副本中安装，不要将参考目录当完整仓库。新包不需要先安装上一版惯量修复包；安装器也识别上一版已交付的对应配置校验值。

```bash
python scripts/install.py --repo /absolute/path/to/linkagent
python scripts/install.py --repo /absolute/path/to/linkagent --apply
```

默认 dry-run。`--apply` 会备份两个原代码文件，并新增资产/参数/接入文件，不覆盖旧 URDF 或旧 USD。

之后，使用原来的 Physics-v1 或 Physics-v2 启动命令，前面增加：

```bash
LINKAGENT_PHYSICAL_PRIOR=1 <原来的 Physics-v1 或 Physics-v2 启动命令>
```

不要同时设置 `LINKAGENT_INERTIA_FIX=1`。Clean-v5 不接入本候选，避免其旧主动跟随控制冒充被动机构。首次只做少量环境的资格检查，使用独立实验名，不直接续接旧检查点作为正式结果。

启动时检查原始 USD 依赖及新资产内容校验和；如果完整几何缺失或源码已变，明确拒绝启动，不静默退回旧资产。配置改动已做静态/API 桩测试，尚未在真实 Isaac Python 环境导入执行。

禁用：移除 `LINKAGENT_PHYSICAL_PRIOR` 或设为 0。

完整回退：使用安装器打印的备份目录。默认仍是 dry-run，确认后添加 `--apply`。如果已安装文件被你修改，回退会停止以保护你的改动。

```bash
python scripts/install.py --repo /absolute/path/to/linkagent --rollback /absolute/path/to/backup
python scripts/install.py --repo /absolute/path/to/linkagent --rollback /absolute/path/to/backup --apply
```

建议独立虚拟环境安装 `numpy`、`mujoco==3.14.0`、`usd-core==26.8`。本包包括用于复现的文本参考层，不含缺失的大几何。

```bash
python scripts/build_prior.py --source-repo reference/source_repo
python scripts/finalize_manifest.py
python scripts/check_geometry.py
python scripts/validate_prior.py
python scripts/contact_probe.py
python scripts/test_integration.py
```

USD 缺少原始几何的警告是已知缺口，不能当成完整场景加载成功。GitHub 版本保留结构化验证结果；含运行环境路径的原始诊断日志未提交。
