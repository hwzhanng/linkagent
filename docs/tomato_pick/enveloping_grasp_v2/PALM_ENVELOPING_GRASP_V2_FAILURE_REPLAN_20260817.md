## 1. 本轮结论

当前“结果不理想”不是训练时间单一不足，而是策略已经学会了**掌托接触/部分近端包络**，却没有学会“在不把果实推出掌心的情况下完成五指远端承力”。最直接的失败链为：

```text
粗/根部通道逐步饱和
        ↓
接触时产生横向冲量，果实偏离掌心
        ↓
虚拟远端接触仍可提供形状奖励，掩盖实测远端接触缺失
        ↓
策略无法形成全五指实测承力；随后掉落或触发过载
```

平滑动作已经证明“降低单步冲量”有效，但尚未解决远端接触和最终摘取。因此下一轮不能直接扩大随机化或继续盲目增加 PPO 更新，而必须按 **动作安全 → 真实接触可观测 → 五指保持 → 摘取** 的顺序推进。

- 这不是“没有动作”，而是动作把果实从掌心推出；第 65 步之后力和接触归零，进入自由落体。

### 2.3 已确认的传感器事实

- 原始 USD link4 接触体在固定探针中覆盖率为 0；v2 增加的 fingertip proxy 是仿真审计工具，不等于实机传感器校准。
- 虚拟远端接触可提高 reach/shaping 信号，但如果不与实测接触分开，策略会把“接近/运动”误当成“指尖承力”。
- 因而最终成功判定必须继续使用：掌托支持 + 五指当前接触 + 四指 link4 实测承力 + 保持窗 + 摘梗条件；任何虚拟字段都不能替代终止闸门。

## 3. 根因排序

### R1（已证实）：粗通道饱和导致果实离开掌心

当前动作输出在接触后仍允许根部、对掌/展开和远端残差持续增大。平滑 α=0.25 可以降低冲量，但不限制长期饱和；因此会从“安全停留”继续积累到“横向推离”。

**修复方向：** 引入每步动作信赖域、饱和惩罚、掌心偏移/速度惩罚，并在未形成五指实测接触前冻结或低通粗通道。

### R2（已证实）：虚拟远端 shaping 与实测终止之间存在目标错位

虚拟 distal contact 能给出密集奖励，而严格终止使用 raw ContactSensor/link4。策略可优化虚拟量，却不承担实测指尖载荷，造成 `distal_all_rate` 高而 `distal_contact_all_rate` 低。

**修复方向：** 训练日志同时输出 measured/virtual 两套指标；虚拟 shaping 只作为接近引导，权重随课程递减；进入 T0-B 后必须按实测 distal 贡献选 checkpoint。

### R3（已证实）：掌托门控改善了掉落，但缺少“掌托稳定后如何逐指闭合”的阶段目标

稳定 8 步和 60 步渐进使策略更保守，却没有给出清晰的顺序目标：拇指对向、四指根部包络、各远端指节贴合、全五指保持。结果变成“安全等待”而非“完成包络”。

**修复方向：** 将动作课程拆为 `PALM_SETTLE → PROXIMAL_ENCLOSE → DISTAL_LOAD → FIVE_FINGER_HOLD → STEM_BREAK`，每一段只开放相应动作子空间，并要求阶段转换具有连续观测证据。

### R4（高可信）：终止前过载主要是接触瞬间冲量，而非持续高压

平滑分支掉落下降但过载上升，说明控制器在少数接触/对齐瞬间仍出现冲击。应记录过载前后 ±10 步的逐指力和果心速度，区分冲击过载与稳定压力过载。

**修复方向：** 对力变化率、果心横向速度和动作增量增加惩罚；过载不立即失能仿真环境，而是进入“保持/退让”安全恢复子阶段并记为失败。

### R5（待验证）：远端通道/近端辅助的尺度仍不匹配大果径

此前 v2 为弥补 link4 几何距离增加了 distal span 和近端耦合。该修复提高了可达性，却可能让远端命令通过近端运动转化为推挤。需要做 `distal-only / proximal-only / coupled` 三路反事实，不能凭训练曲线判断。

## 4. 新的改进目标与验收门槛

### 4.1 不可放宽的任务定义

- 掌面始终向上；果实初始位置仅在掌心小范围随机化。
- 成功必须满足掌托支持、五指包络、四指远端实测承力、保持窗和摘梗；三指捏取不得计为成功。
- 小果径捏取旧成果继续只读封存；本分支只优化大果径掌托式包络。
- 不通过提高安全压力上限、缩短保持窗、延长掉落宽限或关闭严格实测闸门来制造成功率。

### 4.2 阶段门槛

| 阶段 | 目的 | 必过指标（独立评估，至少 256 回合） |
|---|---|---|
| T0-A 安全稳定 | 掌托不被推离 | 掉落 ≤10%，过载 ≤2%，掌托支持 ≥80%，五指不要求 |
| T0-B 实测接触 | 四指远端真实承力 | 掉落 ≤10%，过载 ≤2%，每指 measured distal ≥50%，四指同时 ≥35% |
| T0-C 五指保持 | 全手包络不退化 | 五指终止接触 ≥40%，保持成功候选 ≥20%，超时 ≤30% |
| T1 摘取 | 在保持后完成断梗 | 严格成功 ≥20%，掉落 ≤10%，过载 ≤2%，五指保持 ≥50% |
| T2 泛化 | 小范围位置/果径泛化 | 三个未见 seed 的严格成功均 ≥20%，最差 seed 不低于 15% |

任何阶段未过，冻结该阶段权重并回退到上一个通过门槛的配置。

### P6：反事实结论（已完成一轮）

- `full14`：掉落 21.71%、过载 5.43%、掌托 76.74%、五指终止 0.78%。
- `freeze_distal`：掉落 13.28%、过载 3.91%、掌托 83.59%、五指终止 0%，但远端实测同时接触仅 7.03%。
- `roots_only`：掉落 20.45%、过载 8.33%、掌托 77.27%、五指终止 1.52%；掌托先行提高到 49.24%，但拇指力积分占比约 49.6%，出现近端/拇指主导。

该反事实证明：远端自由动作是当前主要的稳定性负担，但简单冻结远端不能产生远端接触；下一步必须改成“先近端承托、再按单指近端接触逐一释放远端”，而不是全局同时开放 4 个 distal 通道。

### P7：指尖 proxy 几何敏感性（已完成诊断）

在同一 `t0_p2_per_digit_link3_gate_ppo120/best.pt` 上，仅把仿真物理 fingertip proxy 半径从 6 mm 改为 8 mm：

- 6 mm：掉落 40.00%、过载 7.69%、掌托 57.69%、measured distal-all 23.08%，measured link4 mean 几乎为零；
- 8 mm：掉落 32.56%、过载 7.75%、掌托 66.67%、measured distal-all 27.13%，各指实测观察率约 16.3%/28.7%/31.0%/74.4%，measured link4 平均载荷仍偏低。

增大 proxy 提升了远端“接触观察”并略降掉落，但未形成持续五指承力，说明当前 link4 物理几何/接触刚度仍是主要不确定项。8 mm 结果只能作为仿真几何诊断，不能直接视为实机等效；下一阶段需要对半径、接触 offset/rest offset、果实质量和每指承力持续时间做小规模矩阵实验。

## 6. 下一次实际运行：P3 接触几何与持续承力矩阵

动作课程已经证明“逐指释放”能提高 measured distal 观察率，但不能保证掌托稳定；因此下一步先不继续 PPO 长跑，使用同一 checkpoint 做可归因矩阵：

1. proxy 半径：6/7/8 mm；
2. `contactOffset/restOffset`：默认、较小 contact offset、零 rest offset；
3. 果实质量：0.05–0.12 kg、0.12–0.18 kg、0.18–0.25 kg；
4. 每指承力持续窗：瞬时观察、连续 3 步、连续 8 步、力积分阈值。

每个格子必须记录 `drop/overload/palm_supported/five_digit/measured_distal_all`、逐指 measured link4 力均值、峰值、持续步数和果心速度。矩阵的目的不是挑选最高成功率，而是找出“持续接触而不过载”的可行域；只有出现 T0-A（掉落≤10%、过载≤2%、掌托≥80%）的几何/质量格子，才在该格子上恢复 P3 PPO。

当前 6 mm/8 mm 结果已保存，8 mm 只能作为待校准仿真代理，不能直接写入实机配置。

## 8. T0-B 远端探针与冻结粗动作复盘（2026-08-17）

### 8.1 已完成实验

- 在已通过 T0-A 的 `p4_contact_retention_radius8_ppo80/latest.pt` 上增加了仿真专用、掌托稳定后才启用的 distal probe。固定 `max_scale=0.4/ramp=160`，探针动作 0.14 的 128 回合检查为：掉落 7.81%、过载 0%、掌托 92.19%、measured distal-all 10.16%；它只在小样本上保持 T0-A，T0-B 仍远未达到（index/middle/ring/little 约 10.16/14.06/14.06/50.78%）。
- 将探针提高到 0.20 在 128 回合为掉落 7.81%、过载 0.78%、掌托 91.41%、measured distal-all 9.38%；提高到 0.30 则掉落 17.97%（长 ramp 仍 21.48%），掌托 82.03%/78.52%。结论是“加大远端推进”在 0.20–0.30 附近跨过安全边界，不能用更强 probe 换 T0-B。
- 增加逐指 staggered ramp 和 index 单指加权 probe 后，measured distal-all 可升至 15.50–18.32%，但掉落为 16.28–23.85%，其中 vector probe 过载 2.29%；均不通过 T0-A。
- 联合弱教师 + probe 的 `t0b_probe_teacher_ppo100`（256 回合）最佳/最新分别为掉落 17.37/22.52%、过载 0.77/0.38%、掌托 82.63/77.48%、measured distal-all 13.13/16.79%；教师退出后的 actor 仍不安全。
- 冻结粗动作、只训练 distal 输出的 `t0b_freeze_coarse_distal_ppo100` 为掉落 15.27%、过载 1.53%、掌托 84.73%、measured distal-all 12.60%；加入连续 raw link4-force shaping 后的 `t0b_freeze_coarse_measured_force_ppo80` 为掉落 17.42%、过载 2.27%、掌托 81.44%、measured distal-all 14.02%。这排除了“单纯冻结粗策略”以及“把二值触觉奖励改成连续力奖励”即可解决问题的假设。
- distal→proximal assist 0.90 的只读对照为掉落 15.50%、过载 0.78%、掌托 84.50%、measured distal-all 13.95%，默认逐指增益也没有恢复 T0-A；增益放大同样不是单调解。

### 8.2 当前根因收敛

1. 传感器通路本身可达：脚本化 contact probe 曾测到 link4 约 0.2–2.4 N；因此不能把 measured 为零归因于传感器完全失效。
2. 安全策略的 distal raw action 在真实 link4 接触前很小，虚拟 shell 在较远处已给出奖励，策略容易停在“virtual distal / proximal local optimum”；探针把指尖推近时又会产生合力冲量，导致掉落。
3. index/middle/ring 的 measured link4 观察率长期低于 25%，little 明显偏高（约 50–77%），说明是逐指动作映射/到达方向和掌托约束的耦合问题，不是单一全局阈值问题。
4. 本轮所有候选严格成功仍为 0%，没有任何权重可发布；T0-A 256 回合安全基线仍是 `p4.../latest.pt` 配合 `max=0.4/ramp=160`，旧 v1 结果继续只读封存。

### 8.3 下一轮执行约束
