# 番茄掌托包络 PPO：训练效果不理想的原因与修订执行计划

版本：v1.3.10（2026-08-17）  
关联执行计划：[PALM_ENVELOPING_GRASP_V2_IMPROVEMENT_EXECUTION_PLAN.md](./PALM_ENVELOPING_GRASP_V2_IMPROVEMENT_EXECUTION_PLAN.md)

## 1. 结论先行

本次结果不理想不是单一的“PPO 训练不够久”。目前证据表明有三类问题叠加：

1. **任务/验证契约不一致**：旧评估器会在自动 reset 后读取状态，且把宽压力、形状、传感器和执行器扰动混在“随机轻度”域中，导致成功率和失败分类都不可信。
2. **策略先验与目标果径不匹配**：冻结的旧捏取策略在 37.5 mm 大果径核心域的严格成功率仅约 11.83%，说明大果径下的可达接触与奖励稀疏本身就是瓶颈，不能只靠延长 PPO 训练解决。
3. **奖励和数值稳定性不足**：第一版 v2 在 update 40 附近出现 NaN；一次高回报并不等于策略学会了掌托包络，且旧三指中间奖励会诱导局部捏取策略。

因此后续采用“先证据链、再单因素课程、再重构奖励和观测、最后逐级扩域”的顺序；旧 v1 权重和捏取结果只读封存，不覆盖。当前最好的稳定实验只能作为诊断性 checkpoint，不能作为交付模型。

## 2. 已完成的证据

### 2.0 接触可观测性闸门（最新）

新增的逐指 scripted probe（15 个环境、固定名义几何、每个直指扫掠远端残差）把原始 ContactSensor 与 v2 仿真指尖代理拆开统计：

| 通道 | 食指 | 中指 | 无名指 | 小指 |
|---|---:|---:|---:|---:|
| 原始 measured link4 首次接触覆盖 | 0% | 0% | 0% | 0% |
| measured link4 最大力 | 0 N | 0 N | 0 N | 0 N |
| v2 virtual link4 代理覆盖 | 100% | 100% | 100% | 100% |
| v2 virtual link4 最大力 | 0.416 N | 0.388 N | 0.438 N | 0.485 N |

原始接触点有效标记仍全部为 false。由此确认：此前严格成功率中的 distal-contact 条件实际由仿真代理满足，不能作为实测触觉或真实 PhysX 接触的证据。相关报告为 `simulation/ppo_tomato_grasp/artifacts/enveloping_grasp_v2/contact_probe_final_20260817_measured.json`；所有产物明确 `hardware_command_allowed=false`。在完成 URDF 碰撞体/ContactSensor 审计并取得 measured link4 非零覆盖前，训练结果降级为“proximal + virtual-distal contact simulation”，不进入 sim2real 或实机部署结论。

### 2.2 训练失败样本

- v2 从零 T0：独立评估严格成功率 0%，终止五指接触约 9.23%，说明策略未形成包络。
- 弱教师混合 T0：成功率约 0.56%，掉落约 61.94%；教师只提供动作先验，不能替代可达性课程。
- 核心域教师训练：早期 rollout 回报升高后在 update 40 左右出现 NaN；已封存为数值不稳定样本。
- 加入 reward/return/value 限幅、非有限保护和低学习率后，迁移训练仍需独立评估，不能把中途回报当作成功率。

### 2.3 最新稳定 T0 与反事实证据

在加入“远端动作只有在接近果面或已有接触后才释放”的门控、显式 teacher 分支和 phase 观测，以及策略 `log_std` 限幅后，`t0_band1_gate_ppo_stable`（E1，35–40 mm 等径，独立 seed 20260820，261 个完成回合）的结果为：

| 指标 | 结果 | 解释 |
|---|---:|---|
| 严格成功率 | **43.68%** | 比 0–25% 的早期版本明显改善，但离 T0 目标仍远 |
| 掉落率 | 54.02% | 主要失败模式仍是包络后保持不足 |
| 过载率 | 2.30% | 已超过当前 2% 拒绝线，不能发布 |
| 五指终止接触率 | 43.30% | 与严格成功接近，说明五指门槛不是唯一瓶颈 |
| 掌托支持率 | 45.21% | 掌托和五指是同一量级，接触顺序不是主要假成功来源 |
| 掌托先行率 | 99.23% | 阶段顺序已基本满足要求 |
| 远端实测接触率（食/中/环/小） | 0.38% / 1.92% / 0% / 4.21% | 绝大多数直指仍由 link3/根部接触，远端奖励不能据此宣称实现 |
| 四指 link3 平均力（N） | 0.149 / 0.082 / 0.073 / 0.134 | 根部接触明显存在 |
| 四指 link4 平均力（N） | 0 / 0 / 0 / 0 | 当前远端传感器/几何覆盖不足，需单独审计 |

同一 checkpoint 的动作反事实（128 环境、同一 seed）显示：完整 14D 成功 40.31%，冻结远端残差成功 41.09%，只保留根部动作成功 14.84%；冻结远端略好于完整动作。这说明旧版本的自由空间远端残差确实会干扰根部闭合，但当前门控仍没有把远端动作转化为可靠的 link4 接触。该结果是“动作门控有效、远端接触尚未解决”，不是 T0 通过证据。

稳定性方面，未加 `log_std` 限幅的门控运行在约 update 70 后出现策略方差膨胀、value 均值塌缩；限幅后 80 update 可稳定结束。因此后续应保留数值护栏，并把“训练曲线看起来上升”与“独立终止快照通过”严格分开。

## 3. 根因排序与修复原则

### A. 证据链问题（最高优先级）

- 所有 done 环境必须先捕获 terminal snapshot，再执行 reset。
- 每回合报告终止码、五指/掌托、掌托先行、实测几何、远端参与、每指接触占空比和最大力。
- 训练和评估必须保存完整 resolved config、观测/动作契约、源文件哈希、父权重和命令。

### B. 大果径可达性与课程问题

- 37.5 mm 等径属于大于旧捏取分布的任务；旧策略的低成功率首先说明接触几何和奖励稀疏，不是简单欠训练。
- 先在 E1（35–40 mm 等径）学习掌托支撑和五指包络，再逐步引入位置、形状、材料、传感器、执行器因素；每次只增加一种因素。
- 过载率达到 2% 立即拒绝当前课程，E7 永远单独报告。

### C. 旧捏取局部最优

- 阶段二“拇指+两指”只能是诊断中间事件，不能产生持续正奖励。
- 成功必须同时满足掌托先行、五指接触、覆盖/对置、低相对速度、力安全和保持窗。
- 四根直指必须产生可测远端（link4）贡献；自由空间弯曲不能获得远端奖励。

### D. 观测和动作问题

- 旧果径归一化在 37 mm 以上饱和；v2 使用非饱和半轴归一化。
- v2 actor 观测为 128D，包含完整 14D previous action、每指 force/rate/contact-age/lost-contact-age/传感器有效位及 proximal/distal load ratio；critic 使用 177D 特权状态。
- 根部预定位与远端贴合使用不同时间常数，远端残差只在接近果面并有接触时获得增量收益。
- 迟滞、死区、回差和状态一致 retention snapshot 必须可测试、可恢复。
- 当前环境的四根直指 aggregate channel 会在 `link3/link4` 中取较大力，而严格远端诊断单独读取 link4；两条链路不能混作“指尖参与”。必须分别报告 proximal-only、link4 measured 和 geometry fallback，并先确认 URDF 碰撞体/接触传感器是否确实覆盖指腹。

### E. 数值稳定性

- reward、return、value 和非有限网络参数都做有限化保护；优势标准化前检查有限性。
- 低学习率、梯度裁剪和教师混合仅用于稳定启动，不得成为长期固定动作脚本。
- 所有“高回报但 NaN/验证失败”的运行保留为失败证据。

| 训练 | 域 | 目标 |

| T5 | 完整摘取和断梗后保持 | 摘取后 2 秒五指保持 ≥90%，不损伤 |

每个阶段使用至少 3 个训练 seed、5 个独立验证 seed；不直接加载旧 Adam 状态。失败时回退到上一个通过阶段，并保留失败 checkpoint。

当前执行顺序必须增加一个“接触可观测性闸门”：

1. 先完成五指 scripted contact probe，要求每根直指在目标球面上能得到非零 link4 measured contact；否则暂停 PPO，修正传感器/碰撞体或把交付声明降级为 proximal-contact 仿真。
2. 在 E1 上用稳定门控配置重复至少 3 个训练 seed；独立验证成功率仍低于 70% 或过载 ≥2% 时，不进入保持课程。
3. 只在 T0 达标后引入 1 秒保持，再逐一加入位置、形状、材料、传感器和执行器随机化；不把 E3–E7 的失败混入单一总成功率。

## 6. 不允许的“修复”

不得通过提高压力上限、降低五指要求、缩短 hold/grace、把 fallback 几何当作 measured contact、复制成功录像或固定旧位姿来提高表面成功率。
