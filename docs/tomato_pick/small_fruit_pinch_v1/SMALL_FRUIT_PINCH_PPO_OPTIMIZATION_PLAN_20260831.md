## 1.1 2026-08-31 P1/P2 实测修订记录

本轮没有直接把 89% 权重复训。先进行了当前左手原生 PhysX 的可达性审计，结论如下：

- 初始 10D 闭合扫描中，拇指/食指有载荷而中指长期为零；原因不是中指接触传感器漏注册，而是父环境的无初始穿透修正把果实沿接近轴推离了三指共同区。
- 在 64 个无初始穿透位置与 14D 关节动作的联合扫描中，得到一个候选：相对经父环境 clearance 修正后的抓取基坐标偏移为 `(0.018, 0.030, 0.024) m`；初始间隙 `13.34 mm`；三指峰值接触力依次为 `0.8421 / 1.1177 / 0.5189 N`；连续三指接触 79 个策略帧。
- 使用该工作区和同一候选动作独立复核时，8 环境、180 步获得一次 `TIM_strict_success`，且无掉落、超载或自碰撞事件；平均三指峰值接触力为 `1.0015 / 1.2239 / 0.4731 N`。

## 2. 新任务的核心定义

### 2.1 果径范围

采用等效直径：

`D_eq = 2 × (a × b × c)^(1/3)`

其中 `a/b/c` 为椭球半轴。以等效直径而不是单个半轴分桶，可避免扁球和长球被错误归入同一尺寸等级。

果径课程定义如下：

| 等级 | 等效直径 | 用途 | 发布含义 |
|---|---:|---|---|
| B0 | 64–70 mm | 旧基线回归域 | 验证迁移未破坏旧能力 |
| B1 | 60–74 mm | 首次双向扩展 | 训练课程 |
| B2 | 56–78 mm | 核心小/中果域 | 阶段验收域 |
| B3 | **52–80 mm** | 最终发布目标域 | 正式成功率必须按尺寸分桶报告 |
| B4 | 48–84 mm | 边界压力测试 | 不达标不阻塞 B3 发布，但必须报告 |

选择 52–80 mm 作为首版正式目标域的原因：

1. 旧权重已在 64–70 mm 上形成稳定策略，便于从中心域向两侧扩展。
2. 旧五指任务在 58–60 mm 左右曾出现明显接触可达性下降；三指捏取具有不同几何关系，必须重新验证，不能直接假定更小果径可达。
3. 低于 52 mm 后，碰撞网格、指尖接触面、触觉阈值和关节标定误差相对果径的占比显著增大，因此先作为压力域处理。
4. 高于 80 mm 后可能自然转入四指或掌部辅助，容易与暂时搁置的大果包络任务混淆。

若 P1 几何门证明 48–52 mm 可稳定三指接触，则下一版将其升级到正式发布域；若 76–80 mm 只能依靠掌心承托，则该尺寸段从纯捏取发布域剔除，而不是放宽成功判据。

### 2.2 手指组合

首版主组合固定为：

- 必须：拇指、食指、中指。
- 可选辅助：无名指。
- 非必需：小指。

正式主成功 `TIM_strict_success` 必须满足拇指、食指、中指三指当前同时形成真实物理接触。另行记录 `T_plus_2_success`（拇指 + 任意两根对向手指），但该宽松指标不得替代主成功率。

设计原因：

- 拇指提供对向支撑，是捏取而非单侧推压的必要条件。
- 食指和中指形成双点对向侧，比纯两指夹取具有更高的抗转动稳定性。
- 无名指允许在较大果径端自适应参与，但不强迫所有尺寸使用相同手型。
- 小指不参与首版成功门，避免为追求“更多手指”重新退化为大果包络任务。

不得通过奖励强迫关节无意义运动。远端关节利用率采用冻结消融、接触贡献和扰动恢复能力证明，而不是设置“每个关节必须移动多少度”的动作配额。

### 2.3 场景边界

- 左腕固定，手掌姿态固定；机械臂搜索、视觉定位和腕部轨迹不进入 PPO 动作空间。
- 果实预置在经过 P1 扫描确认的三指共同可达区，初期不要求策略寻找果实。
- 果实在抓取前不依赖掌心支撑，不使用隐形托盘、捕获力、位置锁定或吸附。
- P0–P6 只训练“接近—三指捏取—低力保持—扰动恢复”。
- P7 才启用固定慢速采摘轨迹和果梗物理。
- 所有接触成功必须来自 PhysX 实体碰撞和明确的接触传感器路径。

### 2.4 连续时序合同

抓取不是“到达一个姿态即结束”的离散事件。首版环境采用 20 Hz 策略频率，并将单回合上限从旧任务约 200 个策略步扩展到 **320 个策略步（16 s）**，为接近、建立接触、压力收敛、长时间持稳和扰动恢复留出明确时间预算。

建议时序预算不是固定动作脚本，而是最长允许窗口：

| 连续过程 | 最大/最小策略步 | 物理时间 | 说明 |
|---|---:|---:|---|
| 初始稳定与对齐 | 最多 40 步 | 2.0 s | 果实与手部状态稳定，策略可提前进入接近 |
| 接近并建立三指接触 | 最多 140 步 | 7.0 s | 未在预算内形成三指接触则判为 acquisition timeout |
| 首次接触后的压力收敛 | 至少 20 步 | 1.0 s | 不能把接触瞬态直接计为抓稳 |
| 连续持稳验证 | **至少 80 步** | **4.0 s** | 抓取后的主要学习目标 |
| 标准扰动后的继续持稳 | 至少 40 步 | 2.0 s | 包含在 80 步持稳窗后半段 |
| 长保持压力测试 | 120 步 | 6.0 s | 正式评估附加项，不用于早期稀疏奖励 |

形成三指接触或首次达到压力带时只设置阶段事件，不立即终止 episode。策略必须持续输出动作，直到完整持稳窗结束后才允许被 Verifier 判定成功。若成功后接触丢失、物体滑移或压力超限，最终结果仍为失败。

环境同时记录 1 s、2 s、4 s、6 s retention curve，防止把短暂夹住误报为稳定抓取。

## 3. 旧权重动作抽搐审计

### 3.1 已确认现象

对封存成功回放 `success_seed47650_env0.npz` 按 20 Hz 采样重新计算：

| 指标 | 整个首成功 episode | 断梗后保持段 |
|---|---:|---:|
| 动作逐步变化绝对值均值 | 0.0336 | 0.0262 |
| 动作逐步变化绝对值 P95 | 0.1165 | 0.0818 |
| 关节速度绝对值 P95 | 0.7595 rad/s | 0.1997 rad/s |
| 关节加速度绝对值 P95 | 8.94 rad/s² | 5.88 rad/s² |
| 关节 jerk 绝对值 P95 | 285.60 rad/s³ | 192.58 rad/s³ |
| 有效方向反转 | 8.70 次/(s·joint) | **10.79 次/(s·joint)** |

这说明肉眼观察到的“关节抽搐乱动”具有可量化证据，不只是渲染帧率造成的视觉错觉。

### 3.2 当前链路的潜在原因

1. 可视化默认使用 `tanh(actor_mean)`，没有默认采样随机动作，因此主要问题不是回放误开探索噪声。
2. 旧环境只对目标位置的一阶变化设置 `command_rate_limit_rad_s=0.45`，没有对目标加速度、jerk 和方向反转频率设置硬约束。
3. `jitter_penalty_weight=0.02` 较弱，并且只惩罚相邻策略动作的一阶差分。
4. 接触判断使用硬阈值；触觉延迟、丢包、陈旧值和接触临界附近抖动可能反复切换策略反应方向。
5. 每指残差可直接同时作用于近端/远端关节，缺少接触前后的速率分层和残差迟滞。
6. 旧动作映射采用绝对目标，虽有限速但没有显式的临界阻尼二阶参考轨迹。
7. 训练的选模指标没有包含动作平滑、关节 jerk、方向反转和接触力振荡，因此高成功但抽搐的权重仍可被选为 best。

## 4. 新动作与协调控制设计

### 4.1 兼容核心 + 远端残差的 14D 接口

前十维保留旧 10D 动作语义：

- 5D 协同动作：全局屈曲、近远端形状、径向/尺侧平衡、指间展开、拇指对掌。
- 5D 每指残差：拇指、食指、中指、无名指、小指。

新增四维为食指、中指、无名指、小指的独立远端残差；它们只影响各自远端关节。Actor/Critic 张量合同相应从 `10D / 110D / 163D` 更新为 `14D / 114D / 175D`。这不是复用旧 Actor 的隐式不兼容修改：版本号、检查点目录和评估报告均独立，旧 10D 权重只读保留。

PPO 原始动作不直接发送给关节目标映射，而经过统一的“协调参考生成器”：

```text
Actor 原始动作（14D）
  → tanh 限幅
  → 接触迟滞与动作相位估计
  → 二阶临界阻尼滤波
  → 每指/每阶段速度与加速度限幅
  → 关节安全投影
  → PhysX PD/力矩控制
```

### 4.2 连续动作相位

相位不是固定时间表，也不指定成功关节位姿，而由距离、接触和载荷连续决定：

1. `PRE_ALIGN`：拇指对掌轴、拇指根部、食指/中指根部快速进入共同工作区。
2. `APPROACH`：三指同步接近，允许较高速度，但限制指间不同步程度。
3. `FIRST_CONTACT`：任一要求手指出现稳定接触后，自动降低该指的闭合速率；未接触手指继续接近。
4. `TRI_CONTACT`：三指均接触后，粗协同动作减速，远端残差负责压力与抗滑微调。
5. `HOLD/RECOVERY`：所有三指继续闭环调节；失压手指允许缓慢补进，过压手指缓慢退让。

不得在 `TRI_CONTACT` 后冻结全手。平滑策略必须通过扰动恢复门，证明其仍能响应，而不是用静止动作伪装稳定。

### 4.3 参考轨迹与限幅初值

以下为仿真首轮初值，P1/P2 可根据接触探针调整：

| 指标 | 接近段 | 三指接触/保持段 |
|---|---:|---:|
| 关节目标速度上限 | 0.45 rad/s | 0.15 rad/s |
| 关节目标加速度上限 | 4.0 rad/s² | 1.5 rad/s² |
| 单步归一化动作变化 P95 目标 | ≤0.08 | ≤0.04 |
| 每指残差最大步进 | 0.04 | 0.015 |
| 接触状态确认 | 连续 2 帧 | 迟滞保持，允许 2 帧短暂缺失 |

滤波器采用状态化二阶临界阻尼实现，状态随 environment reset 清零。滤波参数进入 checkpoint 配置快照，禁止回放时使用与训练不同的平滑器。

### 4.4 协调性指标

除最终成功外必须记录：

- 三指首次接触时间差：`max(t_thumb,t_index,t_middle)-min(...)`。
- 拇指对掌完成时的食指/中指根部位置误差。
- 三指接触后粗协同动作占比与独立残差占比。
- 每指近端/远端关节动作相关性和相位滞后。
- 指间碰撞次数与接触冲量。
- 远端关节冻结消融后的成功率下降。
- 扰动后各指载荷恢复时间。

协调性验收不要求三指绝对同步。推荐行为是根部与拇指对掌先形成几何条件，随后三个指端在较短时间窗内完成低冲击接触。

## 5. 观测、触觉与成功判据

### 5.1 Actor 观测

第一版维持 110D 接口以复用旧权重，但重新审计各字段：

- 果实在手坐标系中的中心、等效直径、三轴比例和姿态。
- 16 个主动关节位置和速度。
- 五指触觉特征；成功手指重点使用拇指、食指、中指。
- 上一步经过滤波后的实际执行动作，而不是未经执行的 Actor 原始动作。
- 触觉特征至少包含载荷、峰值、接触面积、压力中心、分布宽度、载荷变化率、有效/陈旧状态。

旧 PhysX 路径中的 50D 触觉块由标量接触力派生，不能直接称为真实 12×6 触觉矩阵。新任务必须把“PhysX 派生特征”和“未来实机矩阵特征”在 manifest 中明确区分。

### 5.2 接触迟滞

初始仿真阈值：

- 接触进入：`F >= 0.08 N` 连续 2 个策略帧。
- 接触退出：`F < 0.04 N` 连续 3 个策略帧。
- 介于二者之间时保持前一状态。

阈值仅是 PhysX 首轮先验，不代表真实番茄损伤阈值；P1 必须通过静态接触探针验证噪声地板和碰撞偏置。

### 5.3 分指柔性压力带

首轮软目标范围：

| 手指 | 软下限 | 软上限 | 仿真硬上限 |
|---|---:|---:|---:|
| 拇指 | 0.20 N | 1.80 N | 4.00 N |
| 食指 | 0.15 N | 1.50 N | 3.50 N |
| 中指 | 0.12 N | 1.30 N | 3.50 N |
| 无名指（可选） | 0.08 N | 1.20 N | 3.00 N |
| 小指（非必需） | 0.05 N | 1.00 N | 3.00 N |

不要求三指压力相等。奖励鼓励各自落在压力带内，并惩罚单指峰值、力变化率、冲量和持续过压。实机标定前不得把这些数字当成真实果实安全压力。

### 5.4 `TIM_strict_success`

一次正式静态捏取成功必须同时满足：

1. 拇指、食指、中指当前均为有效真实接触。
2. 三指同时接触在 80 个策略步（4.0 s）保持窗内占比 ≥85%。
3. 任一要求手指连续失联不得超过 2 个策略步。
4. 三指载荷在各自软压力带内的时间占比 ≥75%。
5. 无任何仿真硬压力上限超限。
6. 果实相对手坐标系中心漂移 ≤12 mm。
7. 保持窗内相对线速度 P95 ≤0.035 m/s，且无掉落。
8. 无手指自碰撞、关节越界或安全投影。
9. 掌部接触占比 <10%，不得依靠掌托完成成功。
10. 在持稳窗第 40 步附近施加标准扰动，并在扰动后继续保持至少 40 个策略步。

标准扰动首版采用手坐标系 ±X/±Y 方向的 0.25 g 等效加速度脉冲，持续 0.25 s；扰动方向在 episode 内随机。扰动强度必须与果实质量联动，不使用固定力使不同果径受到不公平测试。严格成功只在完整 80 步持稳窗结束后锁存，不能在扰动前提前成功。

## 6. 奖励设计

奖励按连续因果链组织：

```text
共同可达区接近
→ 拇指对掌与两指根部协调
→ 指端距离收敛
→ 首次低冲击接触
→ 三指同时接触
→ 分指压力带稳定
→ 低滑移保持
→ 扰动恢复
→ 最终成功
```

### 6.1 正奖励

- 三个要求指端到果实表面的距离新进展。
- 拇指与食/中指形成对向法向。
- 新增要求手指的真实接触。
- 三指当前同时接触，而非“历史上曾接触”。
- 分指压力落在各自软压力带。
- 接触力变化率降低、果实滑移减小。
- 持续保持进度。
- 扰动后恢复到压力带和中心区域。
- 完整严格成功一次性奖励。

### 6.2 惩罚

- 动作一阶差分、二阶差分和三阶差分。
- 关节速度、加速度、jerk 超过阶段软限。
- 有效方向反转过多。
- 指间碰撞和指尖穿透冲量。
- 单指压力集中、压力峰值、力冲量和持续过压。
- 接触临界附近快速反复进入/退出。
- 掌部支撑、果实滑移、掉落和偏离捏取工作区。
- 关节限位、动作饱和、安全投影和跟踪误差。
- 三指接触后粗动作仍持续大幅改变。

### 6.3 奖励防捷径规则

- 接近奖励采用 `best-ever progress`，保持奖励必须使用当前状态。
- 历史接触 latch 不得持续提供三指接触奖励。
- 虚拟接触、距离阈值和碰撞代理不得进入正式成功。
- 不奖励“动作不变”本身；必须同时满足接触、低滑移和扰动恢复。
- 不以某组成功关节位姿为目标，也不回放旧成功轨迹作为策略动作。

## 7. PPO 迁移策略

### 7.1 网络迁移

- 加载旧 `best.pt` 的 Actor body 和 Actor mean。
- Critic 重新初始化，因为任务奖励和成功定义已改变。
- 优化器重新初始化，不继承旧 Adam 动量。
- 观测归一化重新采样；如需保持旧尺度，先记录冻结基线再渐进更新。
- 旧 Actor 作为 reference policy，使用 KL/均方动作锚定防止快速遗忘。

### 7.2 两速率优化

建议参数起点：

| 项目 | 初值 |
|---|---:|
| 基础 Actor 学习率 | 1e-5 |
| 新残差/适配头学习率 | 1e-4 |
| Critic 学习率 | 3e-4 |
| PPO clip | 0.10 |
| target KL | 0.010 |
| KL 硬停止 | 0.015 |
| gamma | 0.995（长时序首选；与 0.99 做消融） |
| GAE lambda | 0.95 |
| epochs | 4 |
| rollout horizon | 64 起步，正式长保持分支 96 |
| 熵系数 | 1e-4 起步，按接触率调整 |

首 20–40 update 只训练残差/适配头并冻结基础 Actor body；随后逐层解冻。残差映射幅度从关节安全跨度的 3% 起步，达到动作平滑门后最多放宽到 8%–10%。

### 7.3 训练规模

1. 数值 smoke：8–32 env × 2–5 update，rollout 32/64 对照。
2. 首次学习门：256 env × 50 update，rollout 64。
3. 课程诊断：1024 env × 150–300 update，rollout 64。
4. 正式训练：2048–4096 env，rollout 64；通过显存与吞吐门后用 rollout 96 做长保持续训，每个果径 band 400–1000 update，由独立评估决定是否继续。

增加 episode 长度与增加 PPO rollout horizon 是两个不同操作：episode 固定为 320 个策略步以覆盖完整抓取过程；rollout 使用 64/96 步以改进长时序信用分配，不要求单个 rollout 覆盖完整 episode。训练器必须正确 bootstrap 跨 rollout 的未终止价值。

没有首次三指接触时不得直接延长长训；必须先回到几何、动作映射和接触传感器审计。

## 8. 分阶段实施与验收标准

所有阶段采用“硬门全部通过才晋级”。未通过的 checkpoint 保留为失败证据，不覆盖上一个通过版本。

### P0：封存、复现与抖动基线

目标：固定旧基线并建立可量化的动作质量指标。

工作清单：

- [ ] 记录权重、源码、环境、USD、配置和评估文件 SHA-256。
- [ ] 验证推理默认使用确定性 Actor mean。
- [ ] 用旧成功判据复跑至少 4 seed × 256 episode。
- [ ] 导出至少 3 个成功、3 个超时、3 个掉落/过载轨迹。
- [ ] 新增动作 TV、关节速度/加速度/jerk、方向反转和力振荡统计。
- [ ] 明确旧回放中是否存在自动 reset 混入轨迹的问题。

验收：

- 旧判据复现成功率与 89.6484% 的绝对差 ≤3 个百分点。
- 过载事件率 ≤1.5%，掉落率 ≤2%。
- 所有轨迹能复现相同动作/观测合同，且没有 stochastic 推理混入。
- 生成 `baseline_freeze_manifest.json`、`baseline_eval.json`、`baseline_motion_quality.json`。

### P1：三指工作区与物理可达性门

目标：在训练前确认 48–84 mm 范围内哪些尺寸可以形成真实三指捏取。

工作清单：

- [ ] 按 4 mm 果径分桶扫描 48–84 mm。
- [ ] 扫描果实中心位置、三轴比例和三指预张开姿态。
- [ ] 使用准静态脚本闭合，不使用 PPO 和虚拟 reach assist。
- [ ] 检查指尖、远端链节、指间自碰撞和掌部意外接触。
- [ ] 对 contact offset、rest offset、solver iteration 做敏感性分析。
- [ ] 记录每个尺寸桶的可达姿态比例和压力分布。

每个候选发布桶至少评估 256 个随机场景。验收：

- B0/B1 三指真实同时接触率 ≥95%。
- B2 每个尺寸桶三指真实同时接触率 ≥90%。
- 拇指必须接触，食指和中指不得被无名指替代。
- 掌部辅助率 <5%，自碰撞率 0%，安全投影率 0%。
- 过载率 ≤1%，果实首接触横向弹射速度 P95 ≤0.08 m/s。
- 52–80 mm 中任一连续尺寸段不可达时，先调整果位/手型；不得放大碰撞代理伪造接触。

P1 输出最终发布域决议；默认目标仍为 52–80 mm。

### P2：小果捏取环境与独立 Verifier

目标：建立与大果任务完全分离的 MDP、奖励和成功判据。

工作清单：

- [ ] 新建独立 Python package、config、artifact namespace 和 checkpoint version。
- [ ] 果实不依赖掌面，果梗关闭。
- [ ] 实现三指接触迟滞和分指压力带。
- [ ] 实现 `TIM_strict_success` 和宽松诊断指标，禁止混用。
- [ ] 实现扰动测试和掌部辅助检测。
- [ ] 将 episode 上限设为 320 策略步，并实现 acquisition、settle、hold、recovery 时序指标。
- [ ] 首次形成三指接触时不得自动终止；只有完整 80 步持稳窗结束后才允许成功终止。
- [ ] 增加接触、掉落、过载、动作平滑和自动 reset 单测。
- [ ] 运行无训练脚本探针验证终止码互斥和分母正确。

验收：

- 单元测试和 compile 检查全部通过。
- 人工构造的成功/失压/过压/掉落/掌托捷径均得到正确分类。
- 成功状态必须连续满足而非单帧触发。
- 1 s/2 s/4 s/6 s retention curve 计算正确，且 4 s 前的短暂成功不会进入主成功分子。
- 抓稳后动作、观测和触觉仍持续更新，不存在动作冻结或 success latch 提前终止。
- 训练 reward 与独立 Verifier 结果可不同，Verifier 不读取累计奖励。
- 真实接触关闭或传感器路径错误时，严格成功必须为 0。

### P3：动作协调与平滑控制门

目标：在开始正式 PPO 前消除控制链自身造成的高频抖动。

工作清单：

- [ ] 实现确定性二阶参考轨迹与分阶段速率限制。
- [ ] 实现方向反转死区和接触迟滞。
- [ ] 将上一步实际执行动作写入 Actor 观测。
- [ ] 增加动作一/二/三阶差分日志和奖励。
- [ ] 对旧 Actor 做无学习 A/B：原控制链 vs 平滑链。
- [ ] 执行标准扰动，验证平滑链不会冻结动作。

保持段硬门：

- 动作单步变化绝对值 P95 ≤0.04。
- 关节速度绝对值 P95 ≤0.20 rad/s。
- 关节加速度绝对值 P95 ≤3.0 rad/s²。
- 关节 jerk 绝对值 P95 ≤80 rad/s³。
- 有效方向反转 ≤2.0 次/(s·joint)。
- 3 Hz 以上关节目标频谱能量占比 ≤15%。
- 相对 P0，jerk P95 至少降低 50%，方向反转至少降低 70%。
- 扰动后 0.75 s 内恢复三指接触，1.0 s 内恢复到软压力带。
- 旧 B0 回归成功率下降不得超过 3 个百分点，过载和掉落不得恶化。

### P4：B0 标称域三指捏取 PPO

目标：在 64–70 mm 上用旧 Actor 初始化，完成新严格任务。

工作清单：

- [ ] 重置 Critic/optimizer/std，加载 Actor。
- [ ] 执行残差头冻结—逐层解冻课程。
- [ ] 保持果实形状、摩擦和传感器接近标称值。
- [ ] 每 20–25 update 运行独立固定 seed 评估。
- [ ] 选模同时看成功、过载、掉落和平滑性。

晋级门：3 个训练外 seed，每 seed ≥512 完成 episode：

- `TIM_strict_success` 总体 ≥90%。
- 最差 seed ≥85%。
- 三指同时接触率 ≥95%。
- 压力带保持成功率 ≥85%。
- 4 s 持稳成功率 ≥88%，6 s 长保持压力测试成功率 ≥80%。
- 掉落率 ≤2%，过载率 ≤1%，掌部辅助成功率为 0。
- P3 全部平滑硬门继续通过。
- 冻结全部三指远端关节的反事实成功率至少下降 5 个百分点，证明策略确实使用指尖自由度；若不下降，只记录为“远端冗余”，不得通过强迫运动伪造利用率。

### P5：双向果径课程

目标：从 64–70 mm 向小、向大两端扩展，最终覆盖 52–80 mm。

课程顺序：

1. B1：60–74 mm。
2. B2：56–78 mm。
3. B3：52–80 mm。
4. B4：48–84 mm 压力测试。

采样必须分桶均衡，不允许中心尺寸占据大多数 episode。每次扩展保留至少 35% 的旧通过域样本，防止遗忘。

每个 band 晋级门：3 个训练外 seed，每个 4 mm 桶至少 256 完成 episode：

- 总体严格成功率 ≥85%。
- 每个尺寸桶成功率 ≥80%。
- 最差 seed × 最差尺寸桶 ≥75%。
- 任一桶掉落率 ≤5%，过载率 ≤2%。
- 任一桶掌部辅助成功为 0。
- 52–80 mm 各桶都满足 P3 平滑硬门。
- B0 回归成功率不得比 P4 降低超过 5 个百分点。

B4 只做压力测试：目标总体成功率 ≥60%、无新的安全故障模式。若 B4 连续相邻两个桶达到 B3 门槛，可在下一版扩大正式发布域。

### P6：物理真实性与域随机化

目标：在不丢失三指捏取语义的前提下提高仿真鲁棒性。

随机化按单因素进入：

1. 果实位置与姿态。
2. 椭球三轴比例。
3. 质量/密度相关随机化。
4. 摩擦、恢复系数、接触刚度和阻尼。
5. 触觉增益、偏置、延迟、丢包和陈旧数据。
6. 执行器响应、偏置、死区、回差和关节阻尼。
7. 最后组合随机化。

正式组合域建议上限：

- 位置扰动：X/Y ±5 mm，Z ±3 mm。
- 轴比：0.85–1.15；极端形状单独压力测试。
- 密度：700–1050 kg/m³，并与体积计算质量。
- 摩擦：0.30–0.90。
- 恢复系数：0–0.06。
- 等效接触刚度：4,000–28,000 N/m。
- 触觉 gain：0.85–1.15，bias：±0.03 N，延迟：0–3 策略步。
- 单指 persistent dropout：≤2%，stale：≤2%。
- 执行器响应比例：0.80–1.08，死区：0–0.006 rad，回差：0–0.010 rad。

验收：5 个训练外 seed、总计 ≥4096 完成 episode：

- 52–80 mm 组合域严格成功率 ≥82%。
- 每个尺寸桶 ≥75%，最差鲁棒性桶 ≥70%。
- 掉落率 ≤5%，过载率 ≤2%。
- 接触几何合理扰动后成功率变化 ≤10 个百分点；超过则说明策略依赖碰撞代理。

## 9. 选模规则

## 12. 停止、回滚与风险规则
