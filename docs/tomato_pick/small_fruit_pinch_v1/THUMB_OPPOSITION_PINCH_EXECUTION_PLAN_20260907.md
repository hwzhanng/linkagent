## 1. 总目标和非目标

### 1.1 最终动作语义

一次合格抓取必须形成以下连续因果链：

```text
果实位于三指共同可达区
→ 拇指横摆/侧摆先指向食指与中指之间
→ 对向几何连续稳定
→ 拇指、食指、中指共同低速闭合
→ 三个真实接触点形成可承载的力闭合
→ 在不过压前提下抓紧
→ 果梗物理脱离
→ 仅靠三指承受重力并持续动态稳持
→ 外部小扰动后仍可恢复
```

“抓紧”不等于持续提高压力。它指在安全压力带内形成足够的几何约束和摩擦承载，使果实在
断梗、重力和小扰动下不滑落。策略必须在保持阶段继续根据触觉和状态微调，不得在首次接触或
达到某组固定关节位姿后冻结。

### 1.2 明确非目标

- 不加载或训练任何机械臂；训练场景中不存在左臂、右臂和右手。
- 不要求掌部支撑；掌部不得成为成功捷径。
- 不沿用大果五指包络的覆盖角、掌托和五指接触判据。
- 不要求无名指和小指参与；二者保持安全开位并接受碰撞监测。
- 当前不作真实番茄损伤定量和实机 Sim2Real 合格声明。
- 不把固定成功姿态、脚本终点或训练回报当成最终抓取成功。

### 1.3 单左手场景拓扑硬约束

训练环境只允许包含：

```text
World
├── Ground / PhysicsScene
├── LeftHand（唯一机器人 articulation，基座固定）
├── Fruit
└── Stem / disturbance helper（仅在对应课程启用）
```

以下对象即使隐藏、失能或不进入 Actor 观测，也不得实例化到 PPO 场景：

- 左机械臂和右机械臂的任何关节、链节、驱动器或重力补偿逻辑；
- 右手的任何关节、链节、碰撞体或接触传感器；
- 双臂联合 USD 中未被使用但仍参加物理求解的 articulation/link。

如果当前资产只有臂手一体或双臂模型，应从项目内资产生成独立的左手训练 USD/配置，保留左手
关节、碰撞体、惯量和传感器映射，不修改上游 Isaac Lab。环境启动时必须执行 allowlist 断言：

- 机器人 articulation 数量恰好为 1；
- 机器人关节和刚体名称全部属于左手 allowlist；
- 不存在 `R1_Joint`–`R7_Joint`、`L1_Joint`–`L7_Joint` 或 `right_hand_*`；
- Actor、Critic、action manager 和 actuator 中不存在臂或右手字段；
- reset、step 和 close 全程不调用臂 SDK、CAN、网络或真实硬件接口。

该场景拓扑属于不可降低的任务边界，不是性能门槛。

## 2. 唯一几何与成功口径

### 2.1 拇指先对向

开启真实接触点后，用果心 `c`、拇指接触点 `p_T`、食指接触点 `p_I` 和中指接触点
`p_M` 定义：

```text
u_T  = normalize(p_T - c)
u_IM = normalize((p_I + p_M) / 2 - c)
theta_opp = acos(dot(u_T, -u_IM))
```

`theta_opp = 0°` 表示理想对向。另计算拇指到食中指中点连线距果心的最短距离
`d_chord / R_eq`。只有以下条件连续 5 个策略步成立，闭合权限才从“对齐”平滑过渡到
“捏取”：

- `theta_opp ≤ 30°`；
- `d_chord / R_eq ≤ 0.40`；
- 拇指、食指、中指均未发生非目标碰撞；
- 果实相对腕部速度 ≤0.05 m/s；
- 闭合前任一指压力不超过该指软上限的 60%。

该门是状态门而不是定时动作脚本。若对向误差重新超过 40°，闭合速度按误差连续衰减，而不是
突然复位或切换固定姿态。训练后期允许 PPO 自主形成不同轨迹，但必须保持“先对向、后捏取”的
可观测因果顺序。

### 2.2 抓紧与摘后保持

一次最终严格成功必须同时满足：

1. 拇指、食指、中指均为真实物理接触，且接触点/法向/摩擦力有效。
2. 首次三指共同承力前，已经通过 2.1 的对向门。
3. 接触阶段 `theta_opp ≤35°`，`d_chord/R_eq ≤0.45`。
4. 三指接触构成正的摩擦力闭合质量；不得仅以三个压力标量代替。
5. 三指载荷处于各自软压力带，任何手指均未越过硬上限。
6. 果梗必须通过物理载荷或显式审计释放而脱离，不能继续提供位置/姿态恢复力。
7. 断梗后仅靠三指承受重力至少 3.0 s；果心相对手漂移 ≤12 mm。
8. 断梗后接受质量相关的 ±X/±Y 扰动脉冲，并继续保持至少 2.0 s。
9. 保持阶段相对速度 P95 ≤0.035 m/s，无掉落、掌托、自碰撞、关节越界和安全投影。
10. 保持阶段观测、触觉和动作持续更新；首次成功 latch 不得冻结控制器。

首版继续使用当前仿真压力带，但仅作为仿真安全范围：

| 手指 | 软下限 | 软上限 | 硬上限 |
|---|---:|---:|---:|
| 拇指 | 0.20 N | 1.80 N | 4.00 N |
| 食指 | 0.15 N | 1.50 N | 3.50 N |
| 中指 | 0.12 N | 1.30 N | 3.50 N |

三指不要求相同压力。正式训练奖励应鼓励低压力下的稳定力闭合，而不是把三指推向相同目标值。

### 3.5 迁移是否有帮助的硬判定

在完全相同场景预算下并行比较：

1. **Cold**：新 Actor 全随机初始化；
2. **Trunk-transfer**：复制 `model_150.pt` 隐藏层，重置 Actor 输出层；
3. **Full-actor**：完整复制旧 Actor，仅用于诊断，不默认晋级。

每个分支使用相同 3 seed、相同场景清单和最多 100 update。只有 Trunk-transfer 同时满足以下
条件，旧权重才被批准作为正式父模型：

- 达到 50% 新严格成功率所需环境步比 Cold 少至少 20%；
- `theta_opp` 中位数不比 Cold 大 5°以上；
- 断梗保持率不比 Cold 低 5 个百分点以上；
- 过载、掉落和 P95 jerk 均不劣于 Cold；
- PPO 置零后的成功率仍低于完整策略至少 50 个百分点。

若不满足，正式训练采用 Cold；旧权重只保留为反例和控制链回归证据。禁止为了“利用已有成果”
而放宽新成功门。

## 4. 防捷径原则

- 最终成功只能发生在果梗脱离以后。
- `disturbance_due` 必须被环境实际消费并产生可测外力，不能只设置布尔标志。
- PPO 残差置零、Actor 输出打乱和固定引导单独运行都必须无法通过最终门。
- 距离阈值、虚拟接触、指尖刚体中心和历史接触 latch 只能用于 shaping/诊断，不能作为成功证据。
- 固定控制器只允许承担滤波、速率限制和硬安全保护，不能独立完成对向与闭合。
- 每个新 checkpoint 必须绑定环境配置、控制器参数、场景清单、源码和权重 SHA-256；禁止只报告
  一个脱离合同的“成功率”。
- 未通过接触观测和几何可达性门时，不以延长 PPO、增大奖励或放宽碰撞 offset 解决。

## 5. 分阶段工作与校验门槛

本计划不要求只靠本地算力训练出最终完美策略。门槛分成两类：

1. **真实性/安全硬门**：场景只有左手、真实接触、成功发生在断梗后、无掌托/果梗/固定控制器
   捷径、无自碰撞和非有限值。这些门不得降低。
2. **性能目标门**：成功率、覆盖率、保持率、扰动恢复率和平滑统计。它们是期望目标；若在相同
   评估口径下经过有证据的克制优化仍难达到，可以降至“本地继续门”，先产出可运行中间策略，
   后续再迁移到高算力平台完善。

### 5.1 门槛调整规则

- 每个阶段先按目标门执行；连续两次单因素调整仍无改善，才可使用本地继续门。
- 每次最多降低一个主要性能指标，原则上相对降低不超过 10%；累计不得低于下表下限。
- 降低门槛前必须保存失败分布，说明瓶颈是样本预算/收敛速度，而不是接触不可达、指标错误或
  控制器作弊。
- 采用本地继续门晋级的权重统一标记为 `provisional`，可以进入下一课程或外部算力续训，但不得
  标记为最终合格权重。
- 若性能提升伴随对向角、断梗保持、过载或 PPO 消融恶化，不允许降低门槛掩盖问题。
- 门槛变更必须记录原值、新值、理由、证据路径、批准适用的阶段和回退条件。

| 阶段 | 主要目标门 | 本地继续门下限 |
|---|---|---|
| P2 可达性 | 对向到达≥95%，三指接触≥92%，断梗保持≥80% | ≥80%，≥75%，≥60% |
| P3 去捷径 | 零 PPO≤20%，jerk P95≤60，反转≤0.50 | 零 PPO仍≤20%；jerk≤80，反转≤0.80 |
| P4 B0 PPO | 总成功≥85%，最差 seed≥80%，断梗保持≥90% | ≥65%，≥55%，≥70% |
| P5 长保持 | 最终摘取≥82%，条件保持≥90%，扰动恢复≥85% | ≥60%，≥70%，≥60% |
| P6 B3 扩域 | 总成功≥78%，每桶≥70% | ≥60%，每桶≥50% |
| P7 随机域 | 总成功≥75%，每桶≥68% | ≥55%，每桶≥45% |

真实性/安全硬门没有本地继续门。任何 `provisional` 权重进入下一阶段时必须同时保留最近的目标门
候选作为回归基线，不能覆盖或改名伪装成正式通过。

## 6. 训练停止、回滚与重构规则

以下任一条件触发立即停止当前分支并回到最近晋级 checkpoint：

- NaN/Inf、观测或动作维度漂移、终止分母错误；
- 新评估中 PPO 置零成功率 >20%；
- 对向角改善但断梗保持不升，说明只在刷几何奖励；
- 最终成功率上升但 `theta_opp`、弦偏心或力闭合恶化；
- 任一短评过载率 >5%、自碰撞率 >0 或掌部辅助成功 >0；
- 连续两次 25-update 窗口，新严格成功提升均 <2 个百分点；
- B0 回归下降 >5 个百分点；
- jerk 或方向反转连续两个窗口恶化 >20%。

最多允许三次克制的单因素调整，每次只修改一个主要因素并重新执行同一场景清单。三次仍不能
通过时，才允许重构动作空间、观测或课程；重构必须另建实验目录，不覆盖失败证据。
