# 番茄自适应抓取控制台（第一版）

这是面向真实番茄果实的新控制台。它参考软网球控制台的安全门、触觉矩阵和 URDF 预演，但不复用软网球示教位姿。

当前页面采用单页实验台布局，不使用 Tab；果实参数、三指规划、URDF 预演、安全门、触觉反馈和实机权限在同一页面中连续展示。

## 当前设计

- 当前页面只要求填写番茄果径和高度；其余几何量采用保守内部默认值，后续可由视觉模块自动替换。
- URDF 预演只显示左手模型，不叠加番茄示意物，避免把可视化球体误认为真实目标定位。
- 拇指“向食指与中指之间对齐”只作为接近策略中的一个软目标；最终接触位置由果实几何、掌部支撑和触觉闭环共同决定。
- 默认采用软网球 Demo 的拇指/食指/中指三指包络与掌部支撑语义；无名指和小指保持张开并锁定。
- “张开”严格复用 G20 的开张姿态：无名指/小指的侧摆通道保留为 `193、148、105、42` 等开张值，不能把侧摆通道清零。
- 软网球的两个示教位姿只作为弱参考区间，参考权重为低值，几何和触觉闭环可以提前收敛，不要求复现示教值。
- 动作分为根部到位、指尖探索、触觉接触、压力分配、动态保持；每指压力目标独立，不使用相同临界值。
- 控制器直接复用软网球 Demo 的 `SoftBallGraspController` 状态机：张开、快速到位、指尖微调、接触搜索、自适应收紧和动态保持。
- 番茄控制台额外显示拇指指尖动态偏移，并在触觉误差超过死区时以有界幅度（每周期最多 3 raw）修正通道 15；该修正只作用于拇指指尖，不替代原控制器的压力闭环。
- 采摘/扭拽阶段默认锁定，必须在后续完成果梗视觉和力学确认后单独启用。
- 预演只生成安全有界的候选轨迹。真实硬件需要显式环境变量、命令行开关、现场确认和页面解锁。

## 启动

在 `linkagent/` 下运行：

```bash
python3 tools/tomato_grasp_console/server.py --profile demo --port 8790
```

打开 <http://127.0.0.1:8790/>。

只读连接左手（不允许运动命令）：

```bash
python3 tools/tomato_grasp_console/server.py \
  --profile left-flexible --connect --can can0 --port 8790
```

硬件运动模式还必须显式设置 `TOMATO_CONSOLE_ALLOW_HARDWARE=1` 并使用
`--enable-motion`；页面仍需人工解锁，且不自动发送动作：

```bash
TOMATO_CONSOLE_ALLOW_HARDWARE=1 python3 tools/tomato_grasp_console/server.py \
  --profile left-flexible --connect --enable-motion --can can0 --port 8790
```

当前版本的番茄控制台与软网球控制台端口、状态和代码完全隔离。
